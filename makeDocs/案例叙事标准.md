# 案例叙事标准

统一结构版本：`history-narrative-v2`（2026-10-23）。以用户新增后的`docs/cases/tang-xuanzong`为模板，机器清单为`case_structure.json`。宣宗、懿宗、僖宗采用相同的20篇主干文档，其中“文化制度以及影响研究”固定11篇；不再使用先前的“制度以及影响研究”目录。旧稿附录可以额外保留，不为凑齐附录而生成空文档。

## 固定目录与专题

| 目录 | 固定文件 |
|---|---|
| 案例根目录 | 阅读入口.md |
| 年事 | 编年纪事.md |
| 纪传体 | 本纪与人物群体.md；牛李党争与方镇.md |
| 古地理与行政区划 | 历史地理.md |
| 文化制度以及影响研究 | 宦官与监军.md；方镇.md；税收及徭役.md；行政区以及土地政策、流民政策.md；盐铁酒茶矿.md；市场货币或者纸币.md；科举.md；宗教制度与推崇.md；诗词短句话剧以及戏剧小说等.md；边患、起义与多民族政权.md；科技物质生活与礼俗.md |
| 史料与考证 | 整理说明.md；史料与待考.md；出处验证记录.md；研究维度覆盖.md |

文件名沿用宣宗模板，正文标题可以用更准确的学术表述。“市场货币或者纸币”必须辨别铸币、折纳、汇兑与纸币，不预设本朝存在纸币；“诗词短句话剧以及戏剧小说等”须辨文体和时代，不将现代话剧概念倒置到唐代。

“方镇”分册研究军政财政运行；纪传体的“牛李党争与方镇”研究人物与政治关系，两者交叉引用，不复制同一全文。地理分册研究区划、道路与空间证据；土地流民专题研究人口分类、田产与行政措施，不以地名列表代替政策分析。

## 叙事组织

背景综述和独立专题另按`研究成果发布规范.md`组织。三朝共同目录保持稳定，跨朝机制独立写入背景综述，本朝分册说明具体变化。对外成果须包含论点、形成过程、运作机制、证据对读及社会空间影响，不能停在索引摘要。

从同一事件的时间、行动者和空间进入，向制度运作、群体处境及后果展开。编年不是专题的替代品，人物出现也不等于制度分析已经完成。

1. **本纪**：统治起讫、皇帝选择、继承、诏令、政务信息；区分帝王评价与当时行动。
2. **表**：任官、亲族、婚姻、养子、军众、党争、方镇及财赋联系，关系随时间变化。
3. **志**：职掌、行政区划、土地赋役、财政商贸、技术生活、礼俗；早期制度与本期实际运作分别交代。
4. **列传**：人物与社会群体的经历、选择、约束和影响，不以职名罗列代替经历。
5. **合论**：把政治、军队、财政、空间和社会后果联系起来；明确史料直接陈述、现代释读与尚待验证的解释。

## 每一专题的内容标准

按`templates/资料条目.md`提供编号、范围、原纪年和地点；每个核心个案都应有“材料与叙述”“人物、制度与空间关联”“异说与待考”。原文短引、现代释读和作者推断分开。制度专题不能只写“某宦官有权”，还须说明谁下令、谁掌兵、谁控奏报、谁收钱、谁任免、谁核查、谁受罚。

宦官专题至少区分内侍省、枢密、神策军中尉、外镇监军、临时宣慰敕使等身份与使职，不能将它们视为统一的常设权限。合作、竞争、监督者自身问责及对百姓的影响均须落到实际材料；不预设每位监军都阻挠作战，也不把一件成功或失败当作全制度结论。

材料不足的维度须在`研究维度覆盖.md`列明当前证据、缺口与下一步。不得用“已经建了文件”“有关键词”“结构校验通过”冒称已经完成该维度。各朝材料量可不同，核心目录不变。

11专题均须有材料判断、人物制度空间关联及证据边界；有材料的先写具体个案，无本期材料的如实说明已检范围与缺口，禁止空文件或复制前朝结论充数。文化生活专题须分别关注生产、流通、使用、政策和群体处境，不以迎佛仪式代表全国民俗，以宴饮代替酒政，以榷酒代替酿曲工艺。跨朝材料可以两朝互参，但明确宽年代，不重复计为两件年事。

## 原文与证据

使用新版原文接口。先检索再读实际章和上下文，按`templates/出处验证记录.md`记录书名、卷次、版本状态、章ID、段号、来源SHA256、解码状态、查询日期和核对范围。正文中的每个实质性论断以脚注连接登记的本机出处；制度通论、传记追叙、笔记、史臣赞论不能混作同等证据。

改元、即位、战役、奏报和献首可属于不同节点。前朝背景与后朝续事标清；未系年的传记材料不能硬排成逐年事件。不同书的姓名、左右军职、亲属长幼、年月和褒贬不一致时保留差别。

## 目录、加载与兼容

每个案例的`documents`含全部主干文档，`documentGroups`按同一清单分组供阅读器加载；`layoutVersion`标识结构版本。旧路径迁移记录到`legacyPaths`，旧书签通过阅读器路由转向新路径，原稿内容与既有事件编号保留。附录单列“旧稿附录”，不计作缺失维度的完成依据。案例入口必须链接11专题与覆盖记录，年导航继续指向同一编年文档中的稳定锚点。

交付运行`python makeDocs/validate_docs.py`，同时检查结构和正文。结构通过只能说明入口、路径、分组、脚注、出处登记合规，不能替代史料校勘或全部维度验收。
