# SpringHistory · 史地阅读室

一个独立的历史资料制作与阅读项目：以docs保存案例文稿，以makeDocs约束Agent查证和写作，以reader阅读并跳转本机史料。

**启动：双击本目录的「启动史地阅读室.cmd」。** 不需要先打开reader文件夹或运行命令。它会启动本机阅读服务并打开浏览器；已经运行时直接打开页面。

页面地址：[史地阅读室](http://127.0.0.1:18865)。先选择案例，再按事件分期、纪年或专题文稿进入。页面左上角“史地阅读室”返回案例导航；文中脚注可以跳转并调用本机汉籍查询。

## 项目分工

| 位置 | 用途 |
|---|---|
| `docs/` | 唯一的阅读内容目录；所有正式研究输出都放这里 |
| `docs/cases.json` | 案例、时期、事件分期与纪年导航登记表 |
| `makeDocs/` | Agent制作史料文稿的规则、模板、查询工具与校验器 |
| `reader/` | 阅读页面、本机服务和汉籍程序适配器 |
| `readerTool/` | 原文解码、原始RTF归档、严格文本转换与可恢复批量导出 |
| `myHistorySys/` | PostgreSQL原文库、Python查询API、入库与核验工具 |
| `AGENTS.md` | Agent进入项目时须遵循的工作规则 |

目前已登记唐宣宗（846—859）、唐懿宗（859—873）、唐僖宗（873—888）三个分朝案例，采用八篇通用叙事与考证主干，具体制度、事件和文化经济专题按时代选配。牛李党争、宦官监军、方镇不是所有朝代必填模板；原有内容和旧书签保留。共同规范见[案例叙事标准](makeDocs/案例叙事标准.md)，材料缺口分别见各朝“研究维度覆盖”。案例分期是研究导航，不作为史书原有分期。

现行目录分为`docs/cases/王朝资料/`、`docs/cases/时代专题/`、`docs/cases/背景综述/`。时代专题按时代或政权分总专题，背景按研究时期归类；各类通过案例清单和正文链接互参。预留的时代、政权与背景目录只保留位置，有实际文稿后再登记阅读入口。目录迁移保留原案例ID与旧书签映射。

阅读室首页与文章左栏按“背景综述／时代专题／王朝资料 → 案例 → 文档分组 → 文章”显示可折叠目录树。首页默认折叠，阅读时展开当前文章所在分支并高亮；可从左栏直接切换其他案例的文稿。分期、纪年入口仍可从案例的“概览与纪年”进入，未发布的预留目录不出现在阅读树中。

另有[晚唐背景制度综述](docs/cases/背景综述/晚唐时期背景综述/阅读入口.md)及[历史专题研究](docs/cases/时代专题/唐总专题/阅读入口.md)，均可在阅读器选择。前者解释机制与三朝差异；后者分别研究裘甫、银刀军、庞勋、王仙芝、黄巢、王郢、阡能，以及牛李党争、宦官监军与方镇转型，保留安南战事示例。两朝边患起义总览只负责梳理、链接具体研究。五代十国、北宋、南宋完整背景目录目前仅预留，未作为已完成通史发布。

项目根目录原有的年事、纪传体等文件夹保留为迁移前原稿，阅读器不再读取它们。后续修改以docs下的文稿为准，避免修改原稿却看不到页面更新。

## 独立原文库

**本机启动：双击根目录的「启动原文查询服务.cmd」。** 新原文系统不需要打开汉籍窗口。首次部署先用 [readerTool](readerTool/README.md) 将本机文献导出，再用 [myHistorySys](myHistorySys/README.md) 导入 PostgreSQL。查询接口为 [本机原文服务](http://127.0.0.1:18866/docs)，与18865的整理稿阅读器分别运行。导出阶段仍调用本机旧DLL，入库后查询不再依赖它。原始库、导出全文、数据库文件和连接密码均只留本机，不上传开源仓库。

数据库使用用户现有的 PostgreSQL 服务：`127.0.0.1:5432`，库名`springhistory_unicode`、schema为`history`。启动器仅启动查询API，不创建、启动或停止PostgreSQL实例；数据库服务未运行时提示连接失败。旧55439试验副本保留为停止状态的迁移备份。

**未知字符核对：双击「查看未知字符核对记录.cmd」。** 它打开本机离线报告，不启动服务。可按书名、卷章、码位和状态查看原始字节、字体、上下文及已确认的独立阅读视图；生成方法见[readerTool说明](readerTool/README.md)。原文保持不变，未核字符不会凭上下文猜补。

## 制作资料

让Agent执行：“按makeDocs规则制作〔时期／人物／事件〕案例，使用本机汉籍系统核对出处，输出到docs并更新案例导航，完成校验后报告未核项目。”详细流程见[makeDocs说明](makeDocs/README.md)。

独立原文服务启动后，可用 `python makeDocs/query_text.py --book-id B01-137 --query 五年内不加税赋` 查找段落，再用 `--chapter B01-137:20` 阅读完整上下文。它不操作旧窗口，适合Agent查资料；引用仍需保留书名卷次、版本、来源哈希和实际核对范围。

所有新案例均应保留来源、引文、事件年代、地名对应和核查状态。查询任务完成不等于正文已经校勘。

## 启动故障

首次重新安装：在reader目录运行“安装阅读系统.ps1”。本机已安装依赖；通常只需双击根目录启动文件。

从GitHub下载后，需要Windows、Python 3.12及Node.js 20.19+，先运行安装脚本构建页面，再使用根目录启动入口。本机汉籍库不随项目分发；默认安装目录为 `E:\汉籍全文检索系统`，可通过 `HANJI_ROOT` 环境变量指定其他路径。阅读整理稿不要求分发汉籍原程序。

若启动报错，查看 `reader/reader-service.log`。也可以在PowerShell执行：

```powershell
& 'E:\历史地理古籍整理\reader\.venv\Scripts\python.exe' 'E:\历史地理古籍整理\reader\launch_reader.py'
```

阅读服务仅监听本机18865端口。它运行期间会监听并关闭指定汉籍目录下的EndSplash.exe；关闭浏览器不会停止服务或监听。
