# 方镇何时终结：从唐代军区到五代、宋初的权力拆分

研究编号：TH-FZ。范围：唐代形成的军政组织、晚唐五代重组和宋初改变；重点不是寻找一个所有地区、所有权力同日废除的日期，而是区分兵权、财赋、属州、任免与官名分别怎样变化。

## “方镇”为什么不是跨朝不变的制度名

方镇不宜一概等同割据。边防军区、维护贡赋运输的内地军镇、中央能够更换主帅的镇，以及牙兵、地方强人对继任有强影响的镇，各自与朝廷关系不同。节度使官名也不能独自证明其可任免属州、截留财赋或世袭军队。应观察实际权限的组合，而不是看到名号就推定一个地方独立政权。

《新唐书·兵志》将府兵、彍骑、方镇兵和禁军的变化放在唐代整体兴亡中叙述，这可以作为兵制变迁的史家概括，却不是所有地方同时经过同一步骤的现场记录。安史战事扩大地方军事动员，战后军政财权的收回程度又不一致；具体建置年、辖区仍应逐镇核对。[^兵]

## 晚唐不能只有“越来越强”的单线

862年武宁被拆分，说明朝廷能通过外来军队、改属州、分配兵额重组一个军区；六年后[庞勋战争](庞勋起事.md)又说明这种处置可能留下政治和军人社会的后果。军镇“强弱”至少应分别衡量对朝廷的服从、抵御外来战争的能力、对军众的控制及财政动员，不能用一个词合并。[^武]

黄巢战争中，部分旧镇失去保卫贡赋及两京的能力；王重荣先附齐又拒齐，朱温由齐将降唐后获宣武，李克用则在复京后获河东。新力量接收部众、财源与任命，不只是原有每个藩镇按相同比例增强。[黄巢专题](黄巢战争与大齐政权.md)保留了这些阶段和投降关系。[^重]

## 五代的变化：军镇、中央与区域政权重新组合

唐亡不是军镇制度一夜消失，也不是五代只有地方割据。旧军镇、军事集团与新的皇权交替重组，禁军统帅可能转成君主，地方割据力量又可能成为区域政权。各个王朝、诸国的君臣和军队结构不同，不能把907—960当作一个不变的军阀模型。

954年高平之战后，周世宗大简诸军，精锐升上军，斥去羸弱，又令各藩镇送骁勇者到京，选入殿前诸班及骑步诸军。这里有明确的资源转移：地方原先蓄养的强兵，被中央征集、筛选并编入中央组织。不是宋建立之后才突然想到加强禁军；同时，中央变强也不能自动推出地方属州和财赋权限当日一并取消。史书以“近代无比”等语赞其选练成效，是史家评价；可以确认选兵制度动作，不据此证明每次战争都必胜。[^周]

宋初的统属与郡政调整接在这类中央军事建设之后理解，更能说明转型是多年发生于不同环节的过程。若要比较后梁、后唐、后晋、后汉及各区域政权，还须分别核其征兵、任免与财赋，不能把后周这一例扩为全五代所有地区的同一政策。

清华硕士智慧《论唐中部藩镇的演变及其对藩镇格局的影响》（2021，导师张国刚）的官方摘要已读，全文未读。其转向中部军镇功能而不限于河朔的研究问题，有助于检查屏障关中、保护漕运的能力怎样变化；本篇不据摘要接受所有因果判断。[学位库记录](https://newetds.lib.tsinghua.edu.cn/qh/paper/summary?dbCode=ETDQH&sysId=267355)。

## 宋初如何拆分军镇权力：多个节点而非一道总废令

《宋史·职官志》追述宋初召镇帅入京、命朝臣权知军州事，并说明知州掌郡政、赋役、钱谷和狱讼；通判参与兵民钱谷等事务、与守臣通签、能够刺举。应注意这是制度志跨时段归纳，不可把后文所有规则都倒排到960年。知州也并非永远只有文臣，材料明确有文武官参任及边地差别。[^知]

属州关系有更具体的进程：高保寅在怀州时，因受河阳赵普抑制而请罢支郡，传记系于开宝五年即972年任怀州之后的叙事，不宜径补每次上疏的月日；977年杜审进任陕州期间，李干奏请支郡不再隶藩镇、得专达。《太宗本纪》同年又记令支郡专奏。地方可以不经镇帅直接对中央报告，是观察统属关系改变的一个明确节点。[^支]

| 权力层次 | 唐末典型问题 | 宋初可见转型及其边界 |
|---|---|---|
| 属州与奏报 | 支郡受军镇节制，镇帅可居中抑制 | 取消隶属、许专奏；存在972年个案与977年较普遍措施的层次 |
| 郡政及司法财赋 | 镇帅兼多项实际权力 | 知州、通判等承担郡政与通签；逐期规则不能全部提前到建隆初 |
| 军事 | 牙军、镇兵与中央军互相牵制 | 研究须继续核中央兵籍、统帅任免与调发，不能从属州一项推断所有兵权同日归零 |
| 官名与待遇 | 节度使常连着驻镇实权 | 宋初本纪仍大量授节度，官名与实际治州、统兵需逐项区分 |

## 所谓“废除”应怎样表述

若指唐末那种节度使结合多州统属、兵财任免的权力结构，它在宋初经过连续拆分，977年支郡措施是重要节点；若指节度使官名，则没有在这一年全部废掉。《太宗本纪》及职官材料都保留其授任、品位，杜审进传亦有后续节度授职。不能以官名存在证明旧结构完整保留，也不能以制度改造推定名号消失。[^名]

因此本项目以后宋代案例应从本期的地方治理、军政和财政机构提出问题，实际存在何机构便研究何机构；方镇沿革作为独立历史专题在这里收束并留下后续核验问题。研究终点须由权力组合的改变判定，不能由模板要求决定。
