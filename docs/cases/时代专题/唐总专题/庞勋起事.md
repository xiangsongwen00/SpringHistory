# 庞勋起事与徐泗战争（868—869）：从桂州换戍到区域战争

研究编号：EV-PX。军事起点是桂州戍卒北返，后演为徐泗及江淮战争；不能只称一次思乡兵变，也不把后来一切参加者都认作原有八百人。

## 一、边防的成本由谁承担

《通鉴》记徐泗募兵援安南，分八百戍桂州，三年一代的约定到六年仍未履行；军府又以库帑空虚、换戍费用大为由延留。868年七月，许佶等杀都将王仲甫，推粮料判官庞勋，取兵器北还。这里有军役期限、换防运输和军人家庭的利益，并不是一句厌战能概括。最初赴援人数在不同史书条目中有差别，本文不擅自合为同一统计。[^始]

## 二、北返、赦免与追击：冲突怎样重新扩大

八月敕使张敬思赦罪部送，沿路剽掠一度停止；湖南交出甲兵后，戍卒因惧银刀旧事再造武备，经浙西、淮南，招集流亡军人。令狐綯没有擅截已奉赦的军队，泗州杜慆则备城戒严。徐州军府议论温庭皓所谓三难五害：赦后擅杀、父兄讨子弟、牵连甚众，与放纵擅归、失去军纪、内外响应的风险并存。[^返]

元密追击没有如预期歼灭返卒。宿州缺守备而陷，庞勋募民入伍且强迫不愿者，利用汴水舟船和伏兵反击追军，元密及将校战死。此后才决定攻徐州。这条顺序说明夺取徐州不是从桂州出发时就已得到证明的完整计划。取得彭城后，庞勋囚主帅、杀用事军吏及亲族，自称留后、求朝廷授节钺。[^取]

## 三、868年冬：徐、宿、濠、泗为什么重要

徐州是军府中心，宿州和汴水关联粮运、舟船；濠州通淮，泗州当江淮交通之冲。庞勋部据濠而不能迅速下泗，派兵持续围城；辛谠多次渡淮求救、迎粮，显示守城取决于粮、盐、船、增援及救援者是否愿冒风险。淮口、都梁的战斗令官军救援受挫，漕驿断绝；转走寿州的商旅和贡献又遭截夺，战争由徐州的人事问题变成跨区域供给危机。[^泗]

| 阶段 | 主要行动 | 居民与军众的处境 |
|---|---|---|
| 桂州至徐州 | 延戍、北返、赦免与再武装 | 戍卒关注回乡安全，地方担忧返卒与亲属响应 |
| 868年冬 | 取徐宿、围泗、据淮口 | 流民避难；自愿投军与强迫征兵并存 |
| 869年初至夏 | 鹿塘、柳子战败；杀俘官；再出丰萧 | 粮乏、重取商旅富室、搜人当兵，支持关系变化 |
| 869年秋冬 | 宿州倒戈、徐州失守、庞勋败死、濠州余军覆灭 | 政治归附改变；戍卒亲族仍遭集体杀戮 |

## 四、军众扩张如何反过来消耗地方社会

最初有人断锄为兵、家人鼓励入伍，随后庞勋部强募乡村人、抽取富室和商旅财产，原起兵者又掠夺妇女、不能约束。磨山难民被围、旱乏水而死等叙事，说明“徐人”内部处境完全不同。不能以早期欢迎推定其一直得到所有居民支持。康承训集诸道军，朱邪赤心所率沙陀以及吐谷浑、达靼、契苾等部参与，朝廷一方也不是单一族属组成。[^扩]

## 五、869年的转折与结局

鹿塘、柳子等败后，庞勋处死被囚主帅、监军、宣慰使及亲属，迫使城中男子出兵，政治要求由求节钺转入公开对抗。泗州围解，丰县获胜后又在柳子遇伏败退，各寨与地方武装开始另作选择。张玄稔在宿州联络归唐，借入城之便转取符离、徐州，庞举直、许佶死，戍桂州者亲族被杀数千。庞勋另率军出宋亳、循涣水东返，受沙陀及官军追击，至蕲一带败死；十月濠州吴迥余军才被消灭。不能将庞勋个人死亡当作所有战事同日结束。[^终]

朝廷重建控制却没有单靠恢复旧秩序：跨镇会兵、沙陀军功、地方投降与归附的再任用均改变了权力分配。对869年戍卒亲族的杀戮，也不能因镇压成功就省去。该事件在862年[银刀军](银刀军兵变.md)之后延续了集体惩处与安全承诺的问题，但与875年后[王黄战争](王仙芝起事.md)不是一支队伍顺次接班。
