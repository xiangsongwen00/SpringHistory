# 裘甫起义（859—860）：浙东战事、地方动员与招抚边界

研究编号：EV-QF。范围：懿宗即位后，大中十三年十二月至咸通元年；大中是沿用的年号，不能因年号仍旧就把十二月事件归到已去世的宣宗在位期。原纪年月沿旧历。

## 从象山、剡县到区域性动员

《通鉴》先在859年十二月记裘甫陷象山、逼剡县，起初仅记百人；860年正月官军在桐柏观前败，裘甫进入剡县，开府库募兵。二月剡西战事中，他利用三溪水道设伏，使追击的官军半渡受水冲击。兵败暴露出浙东既有军器、训练及募兵执行的问题，地方军吏受赂又使新募兵的实际能力不足。不是朝廷没有下讨伐令，而是能否把命令转成可用兵力。[^起]

随后加入者被史书概称为山海群盗、亡命，组织被记为三十二队，裘甫又自称天下都知兵马使、改元罗平、铸天平印，征集粮食与工匠。材料可以说明队伍在扩张并试图建立统率、制造兵械，不能据史臣贬称断定全体社会身份，也不能将所称三万人视为精确点名册。对田赋、逃户的背景，薛调同年奏议能提供问题线索，但不是每个参加者入伍原因的逐人证据。

## 怎样选择路线：进攻贡赋区域还是据险守海

起事军沿上虞、余姚、慈溪、奉化、宁海扩展。史书同时保留刘暀与王辂的不同主张：前者希望先取越州府库，以西陵、浙江水陆交通控制浙西及扬州，再向福建展开；后者主张利用山海险阻、耕渔供给，急时退海岛。这是两个不同的空间与资源方案。不能把没有执行的建议画成已经到达的行军路线，也不应只用“未采纳正确意见”替代对风险与条件的比较。[^谋]

明州居民自筹钱财、募勇、浚沟断桥自保；越州部分居民准备舟粮逃难，部分官吏又暗通起事军以求城破后保全家属。城内并不是一个意志完全一致的集体。裘甫军沿途俘掠和杀戮的记述亦须纳入，不能只记动员成功、不记不愿参加者的处境。

## 王式如何整合外援、本地兵与流配军人

朝廷改任王式，发忠武、义成、淮南等军。他与侍侧宦官争论发兵费用，所举理由是若久拖，江淮贡赋交通失控将使国家供给受损。王式到越州后先整军令、管门禁和情报，开仓赈济，又把吐蕃、回鹘流配者中的骁健者编为骑兵，给养其家属。这些人有被迁置、困乏、受差别待遇的具体经历；被纳入同一军事行动，不能直接等同于文化身份已经消失。[^军]

东路由上虞向奉化、象山，南路沿沃州、新昌、唐兴推进，本地土团提供引路与兵力。王式对平民、胁从与财物订下不同处置原则，并令已降者立功后奏官。赈济既关乎民生，也被他解释为减少饥民依附起事军、避免县仓转为敌粮的办法；这种解释来自平乱功成后的问答，须与其自我表功的叙述位置一起读。

## 宁海、海口与剡城：战事怎样结束

五月官军在宁海、唐兴南谷、海游镇等处连战，并用水军巡海、焚船，限制起事军向海上退却。裘甫过黄罕岭重新入剡，六月官军围城，议断溪水，起事军多次出战。所谓三日八十三战是史书的战斗次数口径，不是本稿能独立复核的现代战报。裘甫、刘暀、刘庆出城后被捕，王式杀刘暀等，送裘甫入京。刘从简仍率众突围至大兰山，余部至七月才被击破；裘甫八月在京被杀。因此“擒首领”“剡城余部结束”“京师处刑”是三个节点。[^终]

## 后果与研究判断

本次战事显示浙东并非无资源，而是军队供给、居民自保与官府调兵能否被组织起来。平乱所用忠武、义成军后来又随王式到徐州，成为862年处置[银刀军](银刀军兵变.md)的力量；这是可见的人员和调兵联系，不等于裘甫与银刀军有统一组织。裘甫事件结束也没有使晚唐浙东从此安定，后来[王郢海上兵变](王郢兵变.md)及地方乡兵崛起是新的过程。
