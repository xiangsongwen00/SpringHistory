# 两税、折纳、征期与逃户转摊

晚唐背景制度综述 · BG-03 · 更新于2026-10-23

## 问题与结论

三朝财税研究的核心不是简单判断税轻税重，而是说明定额、估价、交付、运输与执行如何将压力分配给不同人群。诏令可以证明政府希望纠正的弊端，地方账簿才能进一步衡量改变了多少。

<a id="background-mechanism"></a>

## 制度形成、结构与运行

租庸调按丁身、户籍和相应的田产组织征取，租是谷物，调随乡土产物，庸与应役或代役有关。《食货一》所载二十日等役限属于其整理的旧制，不是晚唐普通百姓都实际承担同样天数的证明。先说明旧制，目的是识别后来征收依据怎样改变，而不是把早唐数字无条件搬入咸通、乾符。[^旧制]

《食货二》将两税的定型与德宗、杨炎联系，记夏秋两期、“以居者为簿”“以贫富为差”。它改变了按丁口组织的主要计税原则，但不意味着从此只有两种税，更不表示各种役使和额外征发消失。“两”首先说明两次征期；田税、户产估等、折纳和地方附加必须再分开。[^两税]

制度的难处在于计价与交付不总是同一种东西。志书叙定税时计钱，而民户可能交绢帛；钱与绢价变化后，即使名义税钱不变，需交实物也会增加。官府收税时的折估与支付官俸时的虚估还可能不同。这里的物轻钱重不是一个只影响商人的市场现象，而能通过折纳直接改变农户负担。[^折纳]

另一条机制是税额与人口变化脱节。一户逃亡，地方仍被要求完成旧额，就可能将缺额压到留下的人户；负担更重又推动新的逃亡。《食货二》在德宗时期已有明确批评，872年懿宗诏禁止转摊说明这一问题在本朝有新的政策回应。两条材料相隔数十年，不证明每地一直执行同一种办法，却足以建立“旧额压力—逃户缺额—转摊—再逃亡”的制度问题链。[^折纳]

役使还须看名称与实质。史书指出召雇、和市等名目可能掩盖强制；懿宗海运诏要求和雇，却同时禁止扣船，正显示“支付报酬的征用”和“额外侵夺”需要分别核查。判断负担不能只数税目，还要问征收时间、交付地点、运送责任、附加费用和申诉能否奏效。[^海运]

### 征期为什么也会变成负担

陆贽的奏议还把征收时间和生产周期连接起来：蚕事未成而先催绢、农功未毕而先索谷，有现货者可能急卖折价，无现货者则借贷以应限。因而即使不增加名义税额，提前征期也能把风险和成本转给民户。奏议要求随地方风俗、时令调整征期，史书却接着说其建议未获施行；这一点必须保留，不能将提出改革直接写成已经减负。[^折纳]

这条机制说明，判断一项税制不能只有税率表，还要说明生产何时完成、纳税人何时必须交付、借贷由谁提供，以及折价和利息最终由谁承担。晚唐本朝材料中若只见减免诏，而不见征期和附费，结论就应限定在法定项目的变化。

## 三朝之间：延续、调整与断裂

以下以本期个案检验上述机制；旧制度的存在不自动证明每条规定连续有效。

<a id="reign-tang-xuanzong"></a>

### 宣宗：本期变化

大中差科簿将户等、役轻重、刺史检署与县令轮差结合，意在让差役分配留下可检查的依据。灾免、常贡抵下户租与河陇免税属于不同对象的调节工具，应研究其覆盖面，不能合成一句普遍轻徭薄赋。

### 懿宗：本期变化

872年禁止逃户税额转摊，既涉及现存户负担，也保留有承佃户时依前应役的条件。政策没有简单取消所有缺税，而是在承税对象、土地实际经营和地方定额之间重新划线。

### 僖宗：本期变化

卢携赈济建议获准而有司不能行，是执行能力不足的直接材料；复京后的军队掠夺，又说明财政与军纪不能分割。减税诏可能降低法定负担，但不能自动阻止非正式侵夺。

## 证据怎样支持本篇解释

制度志用于识别名称、规则和修史者的概括，本纪与编年用于定位行动节点，列传和笔记用于补充关系、经历及争论。把它们对读，可以说明运作机制；若没有地方簿籍、田契、军府文书或器物，不将规范扩大为全域执行率。正文已给出当前可成立的解释，未解决部分限于具体的数量、地域覆盖、职期或版本异文。
