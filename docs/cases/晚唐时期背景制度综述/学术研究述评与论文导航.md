# 晚唐研究：学术述评与论文导航

本册连接学术研究与本项目已经读取的原文，重点是宣宗、懿宗、僖宗三朝的皇位继承、宦官、军政、财税与地方社会。以下不是检索结果的堆放：每项均说明取得了什么材料、能帮助回答什么问题，以及尚不能据此宣布什么结论。检索与读取日期为2026年10月23—24日。

## 一、先把问题分开

“宦官专权”不足以说明所有事件。郭太后的宗法地位、神策将领的仕途、监军的差遣、枢密的传达和皇帝接收奏报的渠道，是不同层次的问题。研究者对这些层次的区分，有助于重新组织本地《通鉴》中的具体事件；学术摘要本身不能代替那些事件的原文。

军政研究同样需要区分：军镇拥有军队，不等于每次行动都获得统一授权；一道赦书也不等于士卒相信承诺。庞勋回途、王仙芝受官失败、潼关粮援失接，应分别追踪命令传递、群体利益与资源到达。三朝的新研究入口如下。

## 二、硕士、博士论文：已确认的记录与读取层次

### 1. 刘竣承：宦官权力结构与皇权

《唐代宦官权力结构演变及其与皇权关系研究》，清华大学博士论文，2025年，指导教师张国刚。**已读取机构库题录与摘要，未读学位论文全文。** [清华大学学位论文库](https://newetds.lib.tsinghua.edu.cn/qh/paper/summary?dbCode=ETDQH&sysId=299332)。

本项目取其问题意识：将宦官内部的身份、官职和政治关系分开考察。宣宗限制内侍、859年储争与僖宗孟昭图事件仍分别以本地原文论证，不能用摘要给三朝所有宦官排出统一的权力序列。

### 2. 张明：藩镇怎样影响中央军制

《唐五代军制变革研究——以藩镇对中央的影响为中心》，清华大学博士论文，2021年，指导教师张国刚。**已读取机构库题录与摘要，未读全文。** [清华大学学位论文库](https://newetds.lib.tsinghua.edu.cn/qh/paper/summary?dbCode=ETDQH&sysId=270144)。

有助于区分军职名号与实际统兵差遣，并把中央、地方的制度变化联系起来。唐五代是一个跨期研究范围，其中五代的制度结局不能提前当成僖宗朝现状。

### 3. 魏宇汉：神策将领与宦官关系

《唐代神策軍系將領與宦官關係研究》，政治大学硕士论文，2016年，指导教师王德权。**已读取机构库摘要、目录与参考文献；全文入口要求验证，未取得全文。** [政治大学机构库](https://ah.lib.nccu.edu.tw/item?item_id=113729)；[学位论文记录](https://thesis.lib.nccu.edu.tw/thesis/detail/e21096bbb20e068e96add0f95654600f/)。

可用来提出将领任职、收养和外任关系的检验问题。王建与田令孜的关系须按具体时间观察，不能见“养子”就推定其始终受宦官控制。论文个案及统计尚未逐页核读，不转引其未见的表格。

### 4. 猪原达生：官僚制、近侍与家族

《唐代宦官史研究―官僚制・側近集団・ジェンダー―》，大阪大学博士论文，2021年。**取得公开的论文内容要旨及审查结果PDF，已读内容要旨相关部分；该PDF不是博士论文全文。** [大阪大学机构库](https://ir.library.osaka-u.ac.jp/repo/ouka/all/81960/)；[公开要旨与审查结果](https://ir.library.osaka-u.ac.jp/repo/ouka/all/81960/31635_Abstract.pdf)。

其官僚身份与近侍关系的区分，可辅助理解散官、职官、使职为何不能互相替代。不能据此把宦官的家族关系和军政职权合并为单一因果。

### 5. 李君倩：懿安郭氏与中唐皇位继承

《中唐皇位繼承與懿安郭氏關係研究》，中国文化大学硕士论文，2012年，指导教师王吉林。**取得机构库链接的129页PDF；已读题录、摘要、目录及正文第35—40页（PDF第41—46页），其余未通读。** [中国文化大学机构库](https://irlib.pccu.edu.tw/handle/987654321/23287)。

这项研究提示将郭氏的亲属政治位置纳入继承问题，而不只考察拥立宦官。本项目对848年祔庙争论的分析仍依据《通鉴》卷二四八。郭太后死亡的猜疑不等于谋杀已经得到证明。

正文所读部分将武宗未正式建储、皇子受培养的可能性和宣宗拥立者联系起来。其人物关系表包含推测与转引，不能整张表直接转成确定的政治联盟。尤其不能由未立太子推出皇帝主动放弃继承安排；应分别核对册立、名义差遣和实际支持。

### 6. 潘子正：僖宗前期的政治角力

《唐僖宗朝前期（873—880）的政治角力分析》，台湾师范大学硕士论文，2013年，指导教师陈登武。**已核对官方学位库题录与可见摘要，未取得全文。** [台湾博硕士论文系统](https://ndltd.ncl.edu.tw/cgi-bin/gs32/gsweb.cgi?o=dnclcdr&s=id%3D%22101NTNU5493009%22.&searchmode=basic)。

其研究范围使郑、卢冲突、宦官与王黄战争可以按当时的选择展开，而不从唐亡倒推“必然失败”。本项目分别追踪876年王仙芝授官与877年尚君长投降争议，不将两次事件拼成一事。

## 四、题录线索与尚未解决的问题

赵光义《唐懿宗咸通政局研究》的转引存在2016、2018两种年份，尚未找到能裁定的学位库原始记录。本轮不选定年份，也不将其结论写成已读材料。林至轩《从能臣到叛臣——高骈与唐末政局研究》可作为下一轮学位库检索方向，目前不作为全文证据。

现代研究与本地原典的关系是相互检验。若论文摘要提出“权力扩大”，应回到职掌、任命、财政、军事和奏报的具体环节；若原典载有某人“懦怯”“专横”，应辨明这是史臣评价还是事件行动。发生分歧时列出各自证据，不用一个评价替代另一种评价。

## 五、继续核读的次序

优先续读郭氏论文尚未核读的正文、追核其中关于宣宗继统与祔庙的征引；其次取得僖宗前期政治研究及懿宗政局研究的可靠全文；再以墓志、制敕、敦煌文书检验监军任职、军粮和地方经营。学位论文的证据链、样本边界与异议处理，比单纯增加论文数量更有价值。
