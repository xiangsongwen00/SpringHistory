# 铜钱、布帛、估价与汇兑信用

晚唐背景制度综述 · BG-06 · 更新于2026-10-23

## 问题与结论

当前材料支持将飞钱、便换列为信用与异地支付研究，支持分析铜钱与实物的财政换算；尚不支持宣称三朝已建立国家流通纸币制度。这个判断来自支付机制的辨析，并非以“尚待考证”回避货币史。

<a id="background-mechanism"></a>

## 制度形成、结构与运行

唐代市场和财政同时使用铜钱、谷物、绢帛以及各种债权凭据。计税用钱、交付用帛、军队领粮和商人异地结算，可以在同一交易链上先后发生。因此不能把史书的钱数全部当作实际搬运的铜钱，也不能见到纸写文牒便认定已出现流通纸币。[^估价]

《食货四》所叙宪宗时飞钱，是商人把钱交给京师的进奏院、诸军诸使或富家等，再凭相合的券在异地取钱；朝廷曾限制，亦尝由三司参与。它解决携钱远行的负担，依赖可兑付的对方与网络。若要称为纸币，尚须证明凭证如何发行、流通、转让、定额和受偿，不能仅凭“券”字完成判断。[^飞钱]

两税折纳说明货币估价怎样进入财政：名义欠钱与实际纳绢之间，由估价决定交多少；货轻钱重时，农户必须拿更多产品换足税钱或抵足税额。对民户而言，这是实物劳动负担的变化；对持钱商人而言，则可能产生买卖时机和库存利益。官府的折估、市场比价与商人实际成交价格又不可混成一种。[^估价]

市场还需要财产权和信用的保护。867年商人持便换文牒却被地方以供军指挥为由留款，中央财政随后也因商人不再信任而支用不足。875年前后两市商旅宝货被籍入内库，则是强制征取对经营安全的冲击。这两件事各有时代和机构背景，却共同说明市场繁荣不能只从物价、币量解释，还须看履约与申诉渠道。[^信用]

## 三朝之间：延续、调整与断裂

以下以本期个案检验上述机制；旧制度的存在不自动证明每条规定连续有效。

<a id="reign-tang-xuanzong"></a>

### 宣宗：本期变化

会昌铸钱及宣宗复铸为像的叙述，提供宗教器物与铜料流向的联系，但不能直接等同全国旧钱退出流通。将钱币实物、政策文字与市场使用分开，才能解释政策转向的实际范围。

### 懿宗：本期变化

便换奏议的重要性在于链条完整：中央准给文牒，商人到州府请领，地方截留，商人疑惑，度支支用不充。它说明国家财政信用也依赖地方支付，中央和地方不能分别写成两套孤立财政。

### 僖宗：本期变化

两市商旅财货遭强取，不只是消费奢侈的道德故事，还关系到存货、柜坊和外国商旅在京的财产安全。尚无足够价格数列计算其全部经济后果，但受害对象与强制渠道已经可以写清。

## 证据怎样支持本篇解释

制度志用于识别名称、规则和修史者的概括，本纪与编年用于定位行动节点，列传和笔记用于补充关系、经历及争论。把它们对读，可以说明运作机制；若没有地方簿籍、田契、军府文书或器物，不将规范扩大为全域执行率。正文已给出当前可成立的解释，未解决部分限于具体的数量、地域覆盖、职期或版本异文。
