# 从边防指挥到军政财政的地域组合

晚唐背景制度综述 · BG-02 · 更新于2026-10-23

## 问题与结论

方镇势力的变化应写成兵、官、钱、地的重新结合。逐帅、军中推立、朝廷授命、实际到任和收入控制须分别标日期；同一军镇在两年之间也可能发生显著变化。

<a id="background-mechanism"></a>

## 制度形成、结构与运行

“方镇”不宜直接译成一组地位相同的独立国家。观察、节度、团练、防御等名号所标示的军事和行政任务不同，实际控制还要看驻军、所辖州、供给来源及朝廷任命能否实施。军镇常以某州为治所，但军镇辖境、州县政区与将领当年活动范围是三张不同的图。[^军]

《新唐书·兵志》以府兵、彍骑、方镇为“三变”，这是一种回顾唐代兴亡的概括。它有助于提出兵源与养兵方式变化的问题，却不能替代逐朝制度史。府兵时代的轮番宿卫、长期边防驻兵、地方募兵与禁军编制各有组织基础；不能把晚唐军人一律称作原有府兵，更不能把志书的褒贬当作军镇自动导致灭亡的证明。[^军]

方镇运行至少涉及三组关系。朝廷与节帅之间有任命、移镇、讨伐、加官和上供；节帅与军众之间有粮饷、赏赐、军功、将校任用和逐帅；军府与属州百姓之间有送使、征发、司法和商旅通行。监军、幕僚、州刺史和当地强家处在这些关系之间，会合作，也会争夺。军众能推留后不等于朝廷不再有作用，朝廷授节也不等于已经能够更换全部地方将校。[^个案]

财赋是理解地域差异的关键。《食货二》记上供、送使、留州三分，以及节度观察使从治州、属州调费的安排。这是宪宗时调整财政关系的记载，不能视为晚唐各镇每年照额运行；但它明确给出了地方、军府与中央之间不同的收入去向。晚唐所谓截留、争利和拒绝移镇，必须据此追问究竟截留哪项、谁原本收取、拟供哪军。[^财]

## 三朝之间：延续、调整与断裂

以下以本期个案检验上述机制；旧制度的存在不自动证明每条规定连续有效。

<a id="reign-tang-xuanzong"></a>

### 宣宗：本期变化

宣宗时浙东、江西、湖南等地军乱说明逐帅并非河北特有。朝廷能调用邻镇兵讨平，也显示诸镇不是一律对抗中央。地方军政是否服从，要按对象和事件区分，不能只画一张“割据版图”。

<a id="reign-tang-yizong"></a>

### 懿宗：本期变化

徐州从武宁节度到团练调整、再到感化军，机构名号随着军众处置和战后安排改变；同一区域的军镇并非持续不变。河北个别镇的军中推立，与徐州的处置方式又不同。

[进入本朝专题](../tang-yizong/专题研究/方镇.md#case-analysis)

<a id="reign-tang-xizong"></a>

### 僖宗：本期变化

复京联盟将李克用、王重荣、朱全忠等力量暂时联结起来，却没有消除彼此的军费和地盘利益。上源驿、两池盐利与沙苑之战说明联盟破裂有具体条件，不能只归咎于某人忠奸。
