# 教育、贡举、铨选与关系网络

晚唐背景制度综述 · BG-07 · 更新于2026-10-23

## 问题与结论

科举既提供可共同评价的文字标准，也生产师生、同年和礼仪关系。它不能被写成完全排除门第的公平机器，也不能被缩成权贵私相授受。研究应追踪不同环节如何打开或限制具体人的机会。

<a id="background-mechanism"></a>

## 制度形成、结构与运行

唐代入仕不能简化成一次进士考试。《选举上》区别学馆生徒与州县乡贡，列明经、进士等常科，又区分天子诏举的制科。学校资格、送试、考试及第和实际授官是不同环节，门第与地方推荐可在进入考场以前就影响机会。[^贡举]

《选举下》把文选归吏部、武选归兵部，叙身、言、书、判以及注拟、审核、告身。这里呈现制度总目，并非各朝一切细节都不变化；但足以说明取得科第不等于立刻担任有俸实职。已有出身者还须经选授、守选或其他任官方式，幕府辟署又提供另一类机会。将贡举与铨选分开，才能解释诗人为什么及第后仍困顿，或未第而进入军幕。[^铨选]

考试内容亦随政治争论变化。《选举上》记建中二年一度以箴论表赞代诗赋，大和八年复试诗赋，文宗又自出题、议定人数。这些环节表明经术、文学与行政能力之间的关联始终有人争论。李德裕批评门生、期集和曲江题名，既是对结党方式的警惕，也包含其对公卿子弟熟习台阁事务的偏重；志书还对其论作明确评价。不能把一方意见直接宣布为制度的客观效果。[^争论]

宣宗847年复考封彦卿等人，特别适合检验这组张力：父兄居显位可能引起避嫌，文字合程又成为准许及第的理由。杏园宴集恢复后，考试、礼仪和社会交游仍相接。至懿僖时温庭筠、唐彦谦、陆龟蒙的经历，又说明举业、声名、辟署、政治关系和战乱迁徙共同构成士人的生涯。[^个案]

### 门第与资格并不只在考场上发生作用

《选举上》按官品、亲属等规定不同学校的入学资格，也列四门学可容纳庶人俊异的部分；《选举下》又在铨选规范中记保识、身分审查及对某些家类、职业身份的限制。它们说明机会结构既有等级划分，也有不同入口，不能简单写成所有人面对同一道自由竞争的门。规范的存在仍不能直接量化某朝各群体实际入仕比例。[^贡举][^铨选]

身、言、书、判涉及仪容、口语、书写和文书判断，较家谱更强调个人表现，却也需要训练、时间和文化资源。由此可以提出一项有条件的解释：考试和铨选未必消除家族资源的作用，而可能改变它发挥作用的环节。若要进一步证明某一家庭如何培养子弟，还须核其教育、交游和仕历，不能只凭门第名称推断。

## 三朝之间：延续、调整与断裂

以下以本期个案检验上述机制；旧制度的存在不自动证明每条规定连续有效。

<a id="reign-tang-xuanzong"></a>

### 宣宗：本期变化

宣宗复考不等于否定一切门第影响，而是把亲属显位与文字能力的冲突交给皇帝、翰林重新审定。研究这件事要同时写礼部裁量、复考权与宴集关系，而非只评皇帝重视人才。

### 懿宗：本期变化

温庭筠与陆龟蒙的不同道路，说明文学声望未必直接换成顺利授官，幕府可能提供工作和关系资源。但两人的选择与传记评价各有背景，不能把未第都解释为被同一党派打击。

### 僖宗：本期变化

唐彦谦避地汉南、入河中幕府，皮日休又见任职大齐，显示战乱让士人的政治依附与就业地理重组。这里应继续核作品与职期，而不先用最终政权归属给整个人生作单一评价。

## 证据怎样支持本篇解释

制度志用于识别名称、规则和修史者的概括，本纪与编年用于定位行动节点，列传和笔记用于补充关系、经历及争论。把它们对读，可以说明运作机制；若没有地方簿籍、田契、军府文书或器物，不将规范扩大为全域执行率。正文已给出当前可成立的解释，未解决部分限于具体的数量、地域覆盖、职期或版本异文。
