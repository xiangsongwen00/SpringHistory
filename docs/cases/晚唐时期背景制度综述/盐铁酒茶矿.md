# 专卖、征税、生产与军费的不同联系

晚唐背景制度综述 · BG-05 · 更新于2026-10-23

## 问题与结论

本专题可确立的主线是：财政需求通过交易规则、官吏考核和刑罚影响日用品流通，再通过生产户、商人和军府的应对改变执行。研究成果应同时写政府收到什么、其他群体承担什么，不能以“榷课增”代替社会福利判断。

<a id="background-mechanism"></a>

## 制度形成、结构与运行

盐、铁、酒、茶、矿放在同一专题，是因为它们都涉及财政与日用生产，却不意味着它们共用一套专卖制度。应先分别识别官府直接经营、向商人或生产户征税、限定交易渠道、设置刑禁和以某项收入指定供军等方式。盐铁使的名号也不表示其经手收入永远只限盐和铁。[^食货]

《食货四》叙茶政在税茶、加价、榷茶、徙茶树入官场、复纳税及增税之间多次变动；这里必须给每一环节标年代，不能截取最严的一条就称为全唐固定法。大中初裴休茶约区分园户私卖、雇载、居舍侩保与成群私贩，说明国家将生产、运输、居停和经纪各环节都纳入责任链。[^茶盐]

盐法同样牵连地方官考课、亭户、保社、商人及交通节点。《食货四》把盐盗、镇戍场铺堰埭通关牟利与监院官选任相联；因此“禁私盐”不只是抓贩者，还涉及监管人员从非法流通中获利的可能。对生产户、普通消费者、豪商及武装私贩，法令后果并不相同。[^茶盐]

矿冶和酒利还需单独解释。宣宗河湟戍兵衣绢增加后，裴休请山泽之利归盐铁，说明军事支出能推动收入管理调整；志书冶场和产额有特定统计时段，并非每年全国生产。榷酒收入可以说明官府从酒业取利，却不能推知酒坊工艺和消费量。到了僖宗两池争端，问题更直接表现为中央、禁军与河中争夺同一收入的支配权。[^矿酒]

## 三朝之间：延续、调整与断裂

以下以本期个案检验上述机制；旧制度的存在不自动证明每条规定连续有效。

<a id="reign-tang-xuanzong"></a>

### 宣宗：本期变化

宣宗财政整顿兼有限制地方擅赋与强化茶盐刑禁。合法商旅减少沿途乱收，与无合法渠道者面对更严惩罚，可以同时发生；所谓利商或抑商必须先说明是哪一群商人。

<a id="reign-tang-yizong"></a>

### 懿宗：本期变化

懿宗准茶药贸易的诏令发生在安南陷后的边地救恤与联系首领背景中；它不是全国放弃茶税。便换文牒被供军使占留又说明军费压力可以侵蚀贸易信用。

<a id="reign-tang-xizong"></a>

### 僖宗：本期变化

王仙芝、黄巢的私盐经历说明非法流通网络值得研究，却不能把起事成员全归盐贩。885年盐利争端从收入分配转化为移镇与战争，展示军政联盟如何受财源安排影响。
