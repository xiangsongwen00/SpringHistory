# 唐僖宗：方镇

专题编号：XZ-C02。整理日期：2026-10-23。范围：XZ-878-02、XZ-882-02—03、XZ-885-02—03、XZ-887-02。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

<a id="case-analysis"></a>

## 材料与叙述

代北军变、黄巢战事与复京联盟改变了各军的结合方式。朱温归唐后出镇汴州，李克用经征召参与复京，884年上源驿之变又使两者冲突；不能将复京联盟写成一直稳定的统一指挥。[^一] 885年两池盐利与移镇引起战争，887年扬州又经历多方争夺，军事力量、财赋和名义任命反复分离。[^二]

## 人物、制度与空间关联

按任命、到任、驻军、税收、转运和城市控制建表。监军朱敬玫、杨复光、田令孜各有不同干预方式，详见宦官专题。

参[编年纪事](../年事/编年纪事.md)、[本纪与人物群体](../纪传体/本纪与人物群体.md)、[历史地理](../古地理与行政区划/历史地理.md)。同一事件沿用原编号，专题编号用于研究归类，不另算一次历史事件。

## 合论与证据边界

“藩镇割据”不足以说明每一镇的实际结构。城市入据不等于稳定控制全道；将帅养子、军众、幕僚、商人与居民的处境尚须续考。

## 从制度背景解释本朝个案

复京联盟将李克用、王重荣、朱全忠等力量暂时联结起来，却没有消除彼此的军费和地盘利益。上源驿、两池盐利与沙苑之战说明联盟破裂有具体条件，不能只归咎于某人忠奸。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《从边防指挥到军政财政的地域组合》](../../晚唐时期背景制度综述/方镇.md#background-mechanism)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

方镇势力的变化应写成兵、官、钱、地的重新结合。逐帅、军中推立、朝廷授命、实际到任和收入控制须分别标日期；同一军镇在两年之间也可能发生显著变化。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
