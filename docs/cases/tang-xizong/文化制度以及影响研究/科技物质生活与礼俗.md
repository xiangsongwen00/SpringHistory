# 唐僖宗：科技物质生活与礼俗

专题编号：XZ-C11。整理日期：2026-10-23。范围：XZ-884-01、XZ-887-02；宽年代陆龟蒙材料。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

<a id="case-analysis"></a>

## 材料与叙述

884年上源驿置酒设乐、继而发生武力冲突，可研究将帅宴饮、接待礼节与军事信任；有酒不代表已知酒曲、生产或禁榷办法。[^一] 887年扬州高骈被囚道院、其左右燃木像、煮革带，是特定供给受限群体的求生叙事，不作为常态饮食菜单。[^二]

## 人物、制度与空间关联

陆龟蒙传记的舟载茶灶、顾渚租茶、品水、病酒后不饮与低田受潦，提供跨懿僖时期的文人生活材料；没有具体系年者两朝共享但明确标注，不计两次独立年事。[^三]

参[编年纪事](../年事/编年纪事.md)、[本纪与人物群体](../纪传体/本纪与人物群体.md)、[历史地理](../古地理与行政区划/历史地理.md)。同一事件沿用原编号，专题编号用于研究归类，不另算一次历史事件。

## 合论与证据边界

柴薪来源、粮价、酱醋、茶法、酒曲配方、服装材料和生产技术尚有缺口。战乱破坏不能直接推出所有技术停滞；需要工艺文本、器物和地方工程互证。

## 从制度背景解释本朝个案

上源驿置酒与扬州极端饥饿处在不同生活环境，不能混为普遍习俗。茶法和制曲材料提供分析生产条件的参照，而本朝税政与战争材料说明这些条件怎样被财政、军需和破坏改变。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《从工艺流程到日用制度和文化选择》](../../晚唐时期背景制度综述/科技物质生活与礼俗.md#background-mechanism)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

生活史不应只写皇室奢侈与战争饥饿两个极端。常态生产、文人消费、官府课税和非常求生须分别呈现；衣食、器物与礼仪中的等级差异，也要从对象、场合和资源条件解释。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
