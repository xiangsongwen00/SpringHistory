# 唐僖宗：边患、起义与多民族政权

专题编号：XZ-C10。整理日期：2026-10-23。范围：873—888；大齐、南诏、代北及唐廷。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

## 材料与叙述

王仙芝、黄巢起事与南诏入蜀分开叙；黄巢入长安后建立大齐、改元金统，又是从移动军众到政权组织的阶段变化。[^一] 李克用由代北军变、逃入达靼到获赦受召、参与复京，其关系会随政治环境变化，不能固定写成族群对立。[^二]

## 人物、制度与空间关联

代北—河中—关中的军众流动，与江淮—岭南—洛阳—长安的黄巢路线分别绘制。考察军中回鹘出身养子等材料时，名号、养父关系和族属证据不能互代。

## 合论与证据边界

唐廷史书对大齐及地方军众有强烈立场；其行政、财政和居民生活还须独立证据。晚唐至元仅作后续比较范围，不把后来的民族国家边界提前投射到本朝。

## 从制度背景解释本朝个案

大齐、唐廷、地方军镇与皇统竞争并存，需要逐时点说明谁在何处行使权力。李克用的跨境经历及复京联盟可以展示多族群军事合作，也应呈现联盟瓦解后的相互争战。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《从唐廷边疆到并行政治世界》](../../晚唐时期背景制度综述/边患、起义与多民族政权.md)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

晚唐至元可以作为多政权并行与交往融合的长时段研究，但本册只完成三朝主要问题的框架与个案。比较时应沿军政组织、贸易人口、语言文化和统治合法性分别追踪，不预设从分裂必然走向某个统一终点。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
