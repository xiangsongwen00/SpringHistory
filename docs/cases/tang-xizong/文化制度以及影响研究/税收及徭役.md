# 唐僖宗：税收及徭役

专题编号：XZ-C03。整理日期：2026-10-23。范围：XZ-874-01、XZ-880-01、XZ-883-01。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

## 材料与叙述

874年卢携奏关东灾荒、税催与义仓赈给，朝廷允准而有司竟不能行；这是政策与实施相分离的明确记载。880年改元诏对指定灾战地区减税，不能扩大成天下统一减四成。[^一] 883年复京伴有官军暴掠，故恢复唐廷控制并不直接等于居民生计复原。[^二]

## 人物、制度与空间关联

关东税粮、地方义仓、军需与行在财政须连读。征役对象、诏令覆盖地区、官军掠夺和地方税款截留分栏。

参[编年纪事](../年事/编年纪事.md)、[本纪与人物群体](../纪传体/本纪与人物群体.md)、[历史地理](../古地理与行政区划/历史地理.md)。同一事件沿用原编号，专题编号用于研究归类，不另算一次历史事件。

## 合论与证据边界

尚缺大部分州县税簿、义仓库存与实际给付记录。不能由准赈或减税诏倒推出灾民已获救济。全国死亡、逃户与复业比例待考。

## 从制度背景解释本朝个案

卢携赈济建议获准而有司不能行，是执行能力不足的直接材料；复京后的军队掠夺，又说明财政与军纪不能分割。减税诏可能降低法定负担，但不能自动阻止非正式侵夺。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《两税、折纳、征期与逃户转摊》](../../晚唐时期背景制度综述/税收及徭役.md)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

三朝财税研究的核心不是简单判断税轻税重，而是说明定额、估价、交付、运输与执行如何将压力分配给不同人群。诏令可以证明政府希望纠正的弊端，地方账簿才能进一步衡量改变了多少。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
