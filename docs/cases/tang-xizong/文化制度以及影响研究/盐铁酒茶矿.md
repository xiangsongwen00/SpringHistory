# 唐僖宗：盐铁酒茶矿

专题编号：XZ-C05。整理日期：2026-10-23。范围：XZ-875-02、XZ-885-02—03。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

<a id="case-analysis"></a>

## 材料与叙述

王仙芝、黄巢私盐经历出现在起事前因追叙中；这提示专卖、非法流通与地方社会网络的关系，不能说明全体参与者均为盐商。[^一] 885年田令孜争两池盐利供禁军，王重荣以本镇用度反对，继而发生移镇与军事联盟变化；争的是收入控制及军费来源，并非单纯盐价。[^二]

## 人物、制度与空间关联

安邑解县盐池—河中军府—盐铁使—神策军，与江淮转输和行在给养联读。盐课名义归属、实际收纳与支用对象分别登记。

参[编年纪事](../年事/编年纪事.md)、[本纪与人物群体](../纪传体/本纪与人物群体.md)、[历史地理](../古地理与行政区划/历史地理.md)。同一事件沿用原编号，专题编号用于研究归类，不另算一次历史事件。

## 合论与证据边界

两史传记和通鉴对“归盐铁／全隶神策”的表述有别，不抹平。酒、茶、矿的本期法规与生产资料仍需专项补证；未把昭宗朝盐曲借收材料提前列入。

## 从制度背景解释本朝个案

王仙芝、黄巢的私盐经历说明非法流通网络值得研究，却不能把起事成员全归盐贩。885年盐利争端从收入分配转化为移镇与战争，展示军政联盟如何受财源安排影响。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《专卖、征税、生产与军费的不同联系》](../../晚唐时期背景制度综述/盐铁酒茶矿.md#background-mechanism)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

本专题可确立的主线是：财政需求通过交易规则、官吏考核和刑罚影响日用品流通，再通过生产户、商人和军府的应对改变执行。研究成果应同时写政府收到什么、其他群体承担什么，不能以“榷课增”代替社会福利判断。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
