# 唐僖宗：起事、行在与方镇重组（873—888）

整理日期：2026-10-23。核验状态：本机数据库原文已读取；逐字校勘、原版页码、底本出版信息仍待补。数据库的 `decoded_unverified` 状态保持不变。月份用旧历，不转换公历日。

本案例起于咸通十四年七月即位，止于文德元年三月去世、昭宗接位。873年仍沿用咸通；乾符在874年十一月改元。广明、中和、光启、文德的实际改元节点均在编年表注明。[^起讫]

本轮已形成40条编年事项、16个年次入口，围绕王仙芝与黄巢、沙陀及代北诸部、朝廷行在、盐利与禁军财政、汴晋和淮南力量重组展开。此处同时记录大齐和襄王煴政权的建立，不把朝廷文献的合法性称谓当作唯一观察角度。

分期为本稿研究安排：873—876看继承、灾荒与起事；877—880看战事流动及入京；881—884看成都行在、复京和黄巢败亡；885—888看盐利之争、第二次播迁、皇统竞争及地方重组。各分期不意味着前一问题已经结束。

[^起讫]: 《旧唐书》卷十九下《僖宗本纪》篇首、乾符元年十一月、文德元年二三月；《新唐书》卷九段18—19、52；《资治通鉴》卷252、257。本机录入本，相关正文已读，底本版次和页码待核。[查本机原文](hanji://J19下?q=僖宗)；[新纪](hanji://X9?q=文德)。
