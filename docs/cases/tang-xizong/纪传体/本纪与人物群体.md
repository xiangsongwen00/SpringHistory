# 唐僖宗：人物群体、财政与社会专题

整理日期：2026-10-23。与[编年纪事](../年事/编年纪事.md)、[历史地理](../古地理与行政区划/历史地理.md)共用事件编号。以下为按问题组织的纪传专题初稿，不宣称完成各人物全传。

## 皇帝、田令孜与北司内部差异

田令孜因僖宗倚任进入权力中心，掌神策军，并干预内库财货、人事及护驾。杨复光在征召李克用、军事协调中又有不同作用；杨复恭后接替田令孜。宦官不是利益始终一致的单一行动者，内廷与南衙的关系也会随军费、行在和人事变化。[^北司]

## 王仙芝、黄巢及军众

本机《通鉴》把王仙芝初聚众系于874年，875年记其攻曹、濮以及黄巢响应，并追叙二人私盐经营经历；876年蕲州受官安排激起黄巢及军众反对，显示集团内部也有官职分配与出路问题。对应 XZ-874-02、XZ-875-02、XZ-876-02。不能从首领经历推出所有参与者都是盐商，也不能只以“农民”遮去戍卒、亡命、商人等不同群体。[^起事]

黄巢在长安建立大齐、改元金统，须与此前移动作战分开。皮日休在该政权任翰林学士，见两《唐书》与《通鉴》的记载；其受职情境、相关作品与结局须另核，不能以此给全部文学活动下结论。[^大齐]

## 李克用、朱全忠及多族群军事关系

李克用的轨迹包括代北军变、逃入达靼、获赦与被征召、参与复京，不能压成“始终反唐”或“始终忠唐”。《通鉴》记其收纳回鹘等出身的军人作养子，提供了跨族群军事组织的线索；养子名号不等于族属已可一概确定。朱温归唐、赐名全忠、出镇汴州，与其在黄巢集团中的旧身份分列。884年上源驿之变显示复京联盟已经分化。[^军人]

## 盐利与禁军财政：资料条目

事件编号：XZ-885-02—03。案例与范围：光启元年安邑、解县两池盐利、移镇命令与沙苑之战。地点：河中、两池、同州、沙苑及长安，参[历史地理](../古地理与行政区划/历史地理.md)。

**材料与叙述**：《旧唐书》《通鉴》叙藩镇上供受阻、禁军及官属支出难继。田令孜要求将王重荣控制的两池盐利重新归盐铁，用以赡军；王重荣称本镇军费有赖盐课，继有移镇命令和军事对抗。[^盐利]

原文短引：“收其利以赡军”。这是一项军费来源的争夺，并非只围绕食盐零售价格的争议。

**人物、制度与空间关联**：田令孜、王重荣、王处存、齐克让、朱玫和李克用的行动须按盐利归属、移镇诏命、援军结盟分开。中央盐铁系统与地方实际掌握财源并存，朝廷名义职权不能直接等同实收能力。

**异说与待考**：不能把这段材料中的军数、课盐车数直接当作全国统计；须续查相关列传与食货志，并核盐课额、运输和禁军实际领取资料。

## 土地、饥荒、流民与地方管理

874年卢携奏关东饥荒、追税和义仓赈济，《通鉴》明确区分获准与“有司竟不能行”；880年改元诏减免广州、荆南、湖南等受战地区税赋。883年复京叙事还记官军暴掠，显示政权恢复与社会复业不能画等号。现有材料可写逃亡、征敛和供军问题，尚不足建立精确人口损失或地权变化数列。[^社会]

## 方镇、世家与官僚网络

郑畋、卢携对讨军统属和招抚政策有争论；高骈的军事地位、盐铁财货与淮南内争紧密相接。旧纪885年概述诸镇自擅兵赋，适合建立军镇控制表，但其中“据”某州不能一律解释成同一强度的长期统治。世家、婚姻、科举和军将养子网络应分别建档；本轮尚未完成谱系，不把这一时期争执直接续写成牛李党争。[^方镇]

## 文学、礼俗与饮食酒文化

皮日休任职大齐、郑畋参与诏檄、上源驿置酒设乐和873—888年的改元祭告，提供了文学与礼仪的具体场景。上源驿宴饮只证明该场合有酒食声乐，不能作为禁榷酒政策或全国饮酒习俗的依据。887年扬州高骈被囚道院、其左右无食，有燃木像、煮革带等极端饥饿叙事，属于战争生活，不能拿来描述平常饮食。酒曲、酿造、茶法、服饰材料与诗歌文本另列待核。[^生活]

## 从人物进入独立事件

王仙芝、黄巢、尚君长与尚让的关系随合兵、分兵和败亡改变；王郢从军功与待遇问题进入海上战争；阡能部众有受胁迫村民，官军又有冒功杀民。人物传记、军众组织与居民经历须分层，不能把同时发生的起事都接成黄巢统一指挥。
