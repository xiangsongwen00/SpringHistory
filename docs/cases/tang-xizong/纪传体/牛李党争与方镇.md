# 唐僖宗：牛李党争的遗产与方镇网络

范围：本朝；宣宗及以前为背景。整理日期：2026-10-23。

## 材料与叙述

僖宗初韦保衡被贬；郑畋、卢携对军事统属与招抚有争论；田令孜与杨复光、杨复恭亦有竞争。战事中的唐、齐任职与军镇联盟是新的关系，不可直接延续为牛李两党。[^网络]

“牛党／李党”不能作为自动生成党籍的标签；同姓、同年及第、父辈旧交都只提供调查入口。与宣宗稿比较时，先确认关系何时建立、何时改变，以及史家如何解释当事人。

## 合论与待考

本稿将“牛李党争的后续影响”保留为研究问题，尚未建立足以给全朝人事冲突作两党归类的证据。不能因这一旧标签不够解释所有问题，就忽略门第、婚姻和政治旧交的作用。与[本纪与人物群体](本纪与人物群体.md)、[编年纪事](../年事/编年纪事.md)交叉阅读。
