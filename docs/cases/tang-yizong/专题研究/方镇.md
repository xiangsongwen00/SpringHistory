# 唐懿宗：方镇

专题编号：YZ-C02。整理日期：2026-10-23。范围：YZ-862-02—03、YZ-866-01、YZ-870-03、YZ-871-02。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

<a id="case-analysis"></a>

## 材料与叙述

862年分岭南东西道、处置徐州军及调整徐宿濠泗建置；866年河北部分军镇出现军众拥立后继者、朝廷授命的过程；870年徐州复置感化军。制度名号与军众实际力量须按时序连续记录。[^一] 871年州县奏请、将校转官规则又给幽、镇、魏保留旧例，说明中央规范具有地区差别。[^二]

## 人物、制度与空间关联

王式—杨玄质—徐州余军，与沿边经略、监军、供军使是不同链条。方镇不仅影响军事，也影响税赋留用和商人便换。

参[编年纪事](../年事/编年纪事.md)、[本纪与人物群体](../纪传体/本纪与人物群体.md)、[历史地理](../古地理与行政区划/历史地理.md)。同一事件沿用原编号，专题编号用于研究归类，不另算一次历史事件。

## 合论与证据边界

不把河北继承方式泛化为全国世袭。留后、节度任命与实际到任分列；军队数量、地方官任免和上供执行还须逐镇续考。

## 从制度背景解释本朝个案

徐州从武宁节度到团练调整、再到感化军，机构名号随着军众处置和战后安排改变；同一区域的军镇并非持续不变。河北个别镇的军中推立，与徐州的处置方式又不同。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《从边防指挥到军政财政的地域组合》](../../晚唐时期背景制度综述/方镇.md#background-mechanism)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

方镇势力的变化应写成兵、官、钱、地的重新结合。逐帅、军中推立、朝廷授命、实际到任和收入控制须分别标日期；同一军镇在两年之间也可能发生显著变化。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
