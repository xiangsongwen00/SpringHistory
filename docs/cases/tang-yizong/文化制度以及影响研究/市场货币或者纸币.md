# 唐懿宗：市场货币或者纸币

专题编号：YZ-C06。整理日期：2026-10-23。范围：YZ-867-03；咸通八年度支奏。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

## 材料与叙述

867年十月，崔彦昭奏商人按省司文牒到地方请领便换钱，却被以供军使指挥为由占留。奏文同时说商人疑惑、度支支用不充，显示异地财政信用与军需留款相互制约。[^一]

## 人物、制度与空间关联

度支出具文牒、商人垫付及赴地方请领、州府场监实际支付分成不同环节。可与军需征船、军镇留用和盐铁财政联读。

参[编年纪事](../年事/编年纪事.md)、[本纪与人物群体](../纪传体/本纪与人物群体.md)、[历史地理](../古地理与行政区划/历史地理.md)。同一事件沿用原编号，专题编号用于研究归类，不另算一次历史事件。

## 合论与证据边界

原文称“便换文牒”，不能写成流通纸币。没有核得本朝国家发行纸币证据。现有材料也不足计算贴水、兑付率或一般货币供应。

## 从制度背景解释本朝个案

便换奏议的重要性在于链条完整：中央准给文牒，商人到州府请领，地方截留，商人疑惑，度支支用不充。它说明国家财政信用也依赖地方支付，中央和地方不能分别写成两套孤立财政。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《铜钱、布帛、估价与汇兑信用》](../../晚唐时期背景制度综述/市场货币或者纸币.md)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

当前材料支持将飞钱、便换列为信用与异地支付研究，支持分析铜钱与实物的财政换算；尚不支持宣称三朝已建立国家流通纸币制度。这个判断来自支付机制的辨析，并非以“尚待考证”回避货币史。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
