# 唐懿宗：税收及徭役

专题编号：YZ-C03。整理日期：2026-10-23。范围：YZ-861-01、YZ-869-02、YZ-872-02。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

## 材料与叙述

861年颍州为前一年水灾请免租；869年徐宿濠泗战后有免税役、归还田宅与禁妄占的规定；872年六月又禁止把逃户税赋杂差转摊现存人户。灾免、战后复业和逃户管理不是一项全国统一永久减免。[^一]

## 人物、制度与空间关联

中书门下条议—皇帝批准—诸道州府—承佃户与现存户。土地荒废、逃亡和财赋定额的冲突是本专题主线。

## 合论与证据边界

诏令目标与执行成效分开。旧纪869税免句有疑文，保留新纪免三年说；征收簿、赈济人数、招复成效及实际减负幅度待考。

## 从制度背景解释本朝个案

872年禁止逃户税额转摊，既涉及现存户负担，也保留有承佃户时依前应役的条件。政策没有简单取消所有缺税，而是在承税对象、土地实际经营和地方定额之间重新划线。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《两税、折纳、征期与逃户转摊》](../../晚唐时期背景制度综述/税收及徭役.md#background-mechanism)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

三朝财税研究的核心不是简单判断税轻税重，而是说明定额、估价、交付、运输与执行如何将压力分配给不同人群。诏令可以证明政府希望纠正的弊端，地方账簿才能进一步衡量改变了多少。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
