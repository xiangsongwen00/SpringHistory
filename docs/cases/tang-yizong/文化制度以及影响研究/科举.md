# 唐懿宗：科举

## 材料与叙述

温庭筠传记涉及举场经历、入幕与低阶任官；陆龟蒙传又叙举进士不中、从湖苏幕府及拒绝部分仕途机会。两种经历说明科举与幕府并非一条无分岔的晋身路线。[^一] 867年本纪记礼部贡举与吏部宏词选人考官任命，礼部考试与吏部选授应分开。[^二]

## 从制度背景解释本朝个案

温庭筠与陆龟蒙的不同道路，说明文学声望未必直接换成顺利授官，幕府可能提供工作和关系资源。但两人的选择与传记评价各有背景，不能把未第都解释为被同一党派打击。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《教育、贡举、铨选与关系网络》](../../晚唐时期背景制度综述/科举.md)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

科举既提供可共同评价的文字标准，也生产师生、同年和礼仪关系。它不能被写成完全排除门第的公平机器，也不能被缩成权贵私相授受。研究应追踪不同环节如何打开或限制具体人的机会。
