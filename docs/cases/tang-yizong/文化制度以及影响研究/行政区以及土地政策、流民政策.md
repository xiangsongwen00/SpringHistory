# 唐懿宗：行政区以及土地政策、流民政策

专题编号：YZ-C04。整理日期：2026-10-23。范围：YZ-862-02、YZ-863-02、YZ-869-02、YZ-872-02。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

## 材料与叙述

安南陷后，863年诏察访走至海门的将吏官健、量予救恤，并对被驱劫地区税役另作规定；这类战争迁移人口不同于872年诏书中的逃亡户口。[^一] 后者将财政空额、田畴荒废、承佃应役及富贫不均相联，禁止缺额再摊，要求长吏招携抚御。[^二]

## 人物、制度与空间关联

与地理分册连读岭南东西道、静海军、永泰县及资州迁治。军镇、州县、治所与田产登记必须分层，收复安南也不直接表示各溪洞首领均受同样管束。

参[编年纪事](../年事/编年纪事.md)、[本纪与人物群体](../纪传体/本纪与人物群体.md)、[历史地理](../古地理与行政区划/历史地理.md)。同一事件沿用原编号，专题编号用于研究归类，不另算一次历史事件。

## 合论与证据边界

未核得全国性均田再分配。田宅返还、承佃应役和招复是不同政策工具；流民人数、路线、原籍财产、妇幼处境尚缺材料。

## 从制度背景解释本朝个案

安南逃至海门者的救恤与徐州战后田宅返还分别处理不同迁徙情境；872年又把荒田、承佃和逃户税连接起来。本朝政策组合随战争地点而变，不能称为一项覆盖全境的流民法。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《土地、户籍、辖境与人口流动怎样相接》](../../晚唐时期背景制度综述/行政区以及土地政策、流民政策.md#background-mechanism)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

土地人口研究需要把权利与责任放在同一时间和地点：谁耕、谁有田、谁纳税、谁受保护、谁能离开。对古今地名只做经核实的对应，尚不清楚的古道路和边界不画成精确线。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
