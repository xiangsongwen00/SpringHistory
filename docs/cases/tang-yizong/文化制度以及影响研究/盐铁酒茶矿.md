# 唐懿宗：盐铁酒茶矿

专题编号：YZ-C05。整理日期：2026-10-23。范围：YZ-863-02、YZ-864-02、YZ-867-03。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

## 材料与叙述

863年诏准岭北茶药商贩往来，并放开廉州珠池采捕，意在战争中的贸易、首领联系和民生。864年又限制额外扣取商船，说明军运征发会损害商人货物与生业。[^一] 867年度支奏载两税、榷酒、支米价及便换文牒被供军使占留，要求依限送纳、给还商人。[^二]

## 人物、制度与空间关联

把盐铁巡院、度支、供军使、地方场监、商人和边地消费分别定位；榷酒是收入项目，不等同于已获得酒坊生产数据。

## 合论与证据边界

宣宗茶盐法只作前朝沿革。咸通盐法调整、矿冶经营、私盐判例与酒曲工艺尚未完成专项核查，不能直接照搬宣宗篇。

## 从制度背景解释本朝个案

懿宗准茶药贸易的诏令发生在安南陷后的边地救恤与联系首领背景中；它不是全国放弃茶税。便换文牒被供军使占留又说明军费压力可以侵蚀贸易信用。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《专卖、征税、生产与军费的不同联系》](../../晚唐时期背景制度综述/盐铁酒茶矿.md)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

本专题可确立的主线是：财政需求通过交易规则、官吏考核和刑罚影响日用品流通，再通过生产户、商人和军府的应对改变执行。研究成果应同时写政府收到什么、其他群体承担什么，不能以“榷课增”代替社会福利判断。
