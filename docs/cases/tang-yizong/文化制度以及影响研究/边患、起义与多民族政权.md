# 唐懿宗：边患、起义与多民族政权

专题编号：YZ-C10。整理日期：2026-10-23。范围：859—873；南诏、河西、庞勋三线。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

## 材料与叙述

浙东裘甫、徐州庞勋与南诏对安南、西川方向的战争，应分别观察动员基础。庞勋事件从延戍、军饷与北返进入州县战争；南诏则是有自身统治、军事部署和对外关系的政权，不能写作起义的同一类型。[^一] 862年张义潮以蕃汉兵复凉州，提供另一条河西交往与军事合作线索。[^二]

## 人物、制度与空间关联

安南—海门—邕管、桂州—徐州、河西归义军和西川各成空间链。当地首领既可能与唐合作也可能转向南诏，不能用现代民族身份直接推定其选择。

## 合论与证据边界

现有叙事主要来自唐朝史书。南诏内部制度、社会生活与其他文字材料仍需补证；“蕃汉”不直接对应现代民族分类。晚唐至元框架可比较，不混成本朝既成事实。

## 从制度背景解释本朝个案

安南战事应同时研究南诏、唐将、监军和溪洞首领；李维周截报影响唐廷用人，与地方首领转向的原因是两类问题。桂州延戍又使内地军户与边防相接。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《从唐廷边疆到并行政治世界》](../../晚唐时期背景制度综述/边患、起义与多民族政权.md)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

晚唐至元可以作为多政权并行与交往融合的长时段研究，但本册只完成三朝主要问题的框架与个案。比较时应沿军政组织、贸易人口、语言文化和统治合法性分别追踪，不预设从分裂必然走向某个统一终点。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
