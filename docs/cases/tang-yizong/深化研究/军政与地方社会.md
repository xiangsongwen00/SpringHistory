# 桂州延戍怎样变成徐州战争：军费、赦命和地方应对

研究编号：tang-yizong-R02。范围：本朝在位期，必要前后事件另标。更新日期：2026-10-24。原纪年月份沿旧历。

<a id="case-analysis"></a>

庞勋事件不宜只解释为思乡，也不宜从最初八百戍卒直接跳到全局社会起义。本篇追踪四次变化：换戍未行、擅自北返、沿路安置与军械重整、回到徐州附近后的相互不信任。各阶段的诉求和参与人群并不相同。

## 一、延戍决定：军费节省与旧约冲突

《通鉴》追述徐泗募兵援安南、分兵桂州，原约三年一代；已戍六年又因军帑空虚、另发兵费用大而被要求再留。财政理由没有直接消除旧约的约束，反而把维持边防的成本压到原戍军身上。这里军饷、轮替运输和军人家庭时间互相连接。[^延戍]

## 二、朝廷赦命为什么没有终结冲突

八月朝廷遣使赦罪、部送归徐州，北返者一度停止剽掠。随后戍卒在湖南被诱交甲兵，回途又担心到徐后遭类似银刀军的清洗，于是自造甲兵旗帜。赦命并非毫无效果，但能否相信赦命会在终点继续有效，是另一个问题。[^返途]

淮南的决定也有制度条件。李湘主张在高邮设伏截击，令狐綯以未得诛讨敕书、戍卒在境内未暴为由放行。史书批评令狐懦怯，研究仍需辨出其中的授权问题：主动截击已奉赦的军队，会使地方长官承担何种政治责任，不能只以性格词说明选择。

## 三、温庭皓的三难五害：地方并非没有判断

徐州决策中的争论涉及诏释其罪却擅诛、让父兄讨子弟、枝党牵连，以及不惩擅归将引起诸道仿效等风险。此处显示军众与本地亲属关系，使“向叛军开战”不是一个与地方社会无关的技术命令。各方都预判对方可能加害，遂增加武装和截击，反过来使原有保证更不可信。[^徐州]

## 四、战争扩大：兵变起点与后续参与要分开

到徐州后，材料又记求节钺、囚敕使、扩大招兵、地方居民逃难等行动。起初的戍军身份不能概括后来全部参与者；同时后期有农民加入，也不能抹去军镇人事和换戍问题。丁辉2010年论文的检索摘要强调与武宁历次兵变比较，这可作为研究问题；本次未取得可完整阅读的PDF，不按摘要照搬全文结论。[^扩大][^研究]

## 结论

可以成立的解释是：军费不足改变轮替，北返后的安全保证缺少共同信任，地方授权与亲属网络又限制了处置选择。兵变的军事起点、地方社会扩展与朝廷重新建置，应连续叙述而分别取证。
