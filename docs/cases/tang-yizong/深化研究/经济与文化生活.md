# 海门救恤、海运征船和便换信用：咸通财政怎样进入生活

研究编号：tang-yizong-R03。范围：本朝在位期，必要前后事件另标。更新日期：2026-10-24。原纪年月份沿旧历。

<a id="case-analysis"></a>

边防财政并非发生在民生之外。863年安南失陷后的救恤、864年的商船和雇、867年便换被留、872年逃户赋税与873年迎佛仪式，可以从战争和官府怎样组织人口、货物及信用的角度相互对读，但不能说它们全由单一原因触发。

## 一、863年救恤为什么连着茶药与珠池

诏令先察访走至海门的将吏官健、量予救恤，继而涉及安南受驱劫地区的税役，以及溪洞首领和岭北茶药的往来，最后准廉州珠池采取。这不是只有军队救援的一道命令，而是处理战争迁移、首领关系和生活供给的政策组合。[^救恤]

其中“本户两税、丁钱”等有对象与期限，不能扩大成全国免税；准许商人往来，也不等于一概免除所有商税。政策的空间范围和适用人群，必须跟着条文本身走。

## 二、864年：和雇与侵夺为什么会同时出现

《旧唐书》制文记商船受扣、货物滞岸散亡，要求按运米数量牒报盐铁巡院和雇入海船，载米数足后不得再扣。制度上拟以报酬与数量约束征用，实践中却存在借备运名义额外占船的情况。[^海运]

这种损害不止是船租不足，还包括货物无人看守、船期中断、商人不能继续经营。由此可以说明军运对市场的多个影响环节，但没有足够账簿时不估算全行业损失。

## 三、867年：纸面债权怎样受地方军费影响

商人依省司便换文牒赴州府场监请领，却被以供军使指挥为由占留。崔彦昭奏文同时指出商人疑惑与中央支用不充，显示信用受损会反过来影响官府融通。这里的文牒用于请领与核验，不是已证明可自由流通的纸币。[^便换]

| 层次 | 责任或诉求 | 冲突所在 |
|---|---|---|
| 省司 | 按文牒准付、维持支用 | 付款承诺依赖地方兑现 |
| 地方供军 | 保留现金或物资供战事 | 可与省司支付指令冲突 |
| 商人 | 收回垫款并继续经营 | 面临延付与政策不确定性 |

## 四、872年土地逃户：谁继续承担定额

六月条议不许将逃户税赋杂差转摊现存人户，同时保留有承佃户时依前应役的条件。它是在土地经营、人户迁移和官府定额之间重新认定责任，不是宣布所有旧额自然消失。将此与海运、便换连读，能看见官府试图同时维持征收与防止执行伤民的张力。[^逃户]

## 五、873年迎佛骨：仪式、交通与行政承诺

法门寺到长安的路线、城门观礼、内道场和诸寺分配，使禁军、官府、僧团、士女进入同一事件。制文的祈福与减刑又联系农务、狱囚和执行时限，宗教仪式因此也是公开展示统治承诺的场合。参与动机和费用来源仍须分别研究，不能只凭热闹程度断言全国信仰或消费规模。[^迎佛]

## 研究参照与结论

张明2021年博士论文摘要强调使府体制及武职名衔与实际统兵之间的分化，提醒研究军费时先核实职名背后的差遣。本篇的财政链条仍据上述咸通条文，不据该论文摘要补写未经证明的地方机构。[^研究]
