# 阡能起事（881—882）：刑罚恐惧、村寨扩张与招降兑现

研究编号：EV-QN。范围：僖宗成都行在时期的西川。阡能是邛州牙官，不能因队伍后来吸收耕民就抹去其军府身份，也不能把四川同时发生的一切武装活动都算作黄巢的统一部署。

## 逃避惩罚怎样进入地方武装

《通鉴》卷254将阡能因公事违期、避杖亡命，置于陈敬瑄派“寻事人”巡县及谢弘让被诱捕惨杀的叙事旁。这可以呈现刑罚威慑和不确定性怎样影响地方官兵，但谢、阡两事不是同一案件，不能把谢弘让受害当作阡能已经亲历的原因。881年之后，罗浑擎、句胡僧、罗夫子及韩求等相继响应，范围进入双流、新津、邛蜀一带。[^始]

## 官军冒功与起事军胁迫同时存在

882年乾溪官军败后，杨行迁等恐受罚，捕治田绩麻的村民冒充战俘送府杀戮；材料包括老弱和妇女。这直接说明官军问责方式怎样把无关居民卷入战争。另一面，阡能囚住村民家属、迫其作间谍，亦显示入寨和参与未必完全自愿。两种强制须同时说明，不能选一边的暴力来遮掉另一边。[^民]

## 高仁厚的进军与分层招降

高仁厚获任后释放被捕间谍，使其传达只追首领、不牵连胁从的承诺；并整合此前分散寨兵。双流、穿口、新津、延贡各寨先后有军众交出首领。他在降者背上书“归顺”作识别，又让他们先行传播消息，焚寨前先取粮供食。这里可以具体看到安全承诺、身份标记、粮食与信息传播怎样瓦解组织。[^降]

史书强调出军六日即平五首领，是突出将帅智略的成效叙事；不能据此推算所有村寨都在六日内恢复常态。首领与谋主仍遭惨刑，普通胁从者却有释放安排，平定包含差别处置，不是整体无条件赦免。

## 承诺怎样在战后再次受到检验

阡能叔父行全一家三十五人被邛州刺史捕系，背后涉及刺史欲买其田不成的嫌隙。唐溪指出既已公告不问亲党，再杀将损害信用，陈敬瑄因此遣人当众释械。招降是否有效，并不在文告发出时就结束，还取决于地方官能否借追党侵夺土地、上级是否纠正。[^后]

阡能事件适合与[庞勋返途](庞勋起事.md)、[王仙芝尚君长案](王仙芝起事.md)比较赦命信用，但各事件的参与者、地方官府与招降结果不同。不能从一个成功招抚推出晚唐招抚总是有效，也不能从一场背约推出所有告示全无作用。
