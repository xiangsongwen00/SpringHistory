# 王仙芝起事（874—878）：灾荒动员、招抚分歧与黄梅败亡

研究编号：EV-WX。采用《通鉴》874年初聚众、875年攻曹濮并与黄巢合流的分段，不以单一“875年起义”掩去史书的起点差别。王仙芝与黄巢共同作战而非始终同一支军队，首领败亡后军众仍有重新组合。

## 聚众的社会背景及证据限度

《通鉴》卷252先叙关东水旱、州县欺报、赋敛加急与流殍无诉，将王仙芝在长垣聚众系于874年；875年记其与尚君长陷濮、曹，黄巢从冤句响应。对两首领私盐经历的追叙，提示盐业交通与非法经营网络可能有动员作用，却不能证明所有军众都是盐贩。卢携874年灾奏能补出食物匮乏、邻境同饥、附加征敛等环节；灾荒、官府行为与组织形成须连读，不能只用首领个性解释。[^始]

## 876年北方转战与军情失真

宋威在沂州战后误奏仙芝已死，遣散诸道兵，数日后复调，军士因反复动员而怨。王仙芝转攻阳翟、郏城、汝州，迫使朝廷保卫东都与潼关要道。被俘王镣又与宰相王铎有亲属关系，成为后续沟通渠道。战争不是单向地“官军追贼”：军情怎样到中央、何时下调令、道路与城池由谁防守，都直接影响其扩张空间。[^转]

## 蕲州授官为何破裂

876年末，裴渥经王镣与王仙芝接触，开城相见并代奏授官。王铎力主招抚，告身授仙芝左神策军押牙兼监察御史；黄巢和军众反对只给首领出路、不安排共同起事者。受官于是中断，军众又掠杀蕲州并分兵。需要分别呈现受官谈判、首领利益、军众不满与城民遭难，不应将受官简化为全体共同决定或只剩一个忠奸道德判断。[^蕲]

## 877年再次会战与尚君长事件

分兵后仍可能联合，877年王黄攻宋州即是一例。张自勉救宋州后，郑畋与王铎、卢携争其军是否归宋威统属，涉及将帅嫌隙、良将安全与本镇守备。招抚与军事指挥的分歧不能自动套成牛李党争。卷253还记仙芝取安、随等州，唐方援军有失利与擅归，不是所有镇将接受统一而稳定的指挥。[^宋]

杨复光又与仙芝交通，尚君长等赴降，宋威却在途中夺取，报为交战所俘。归仁绍奉命审讯，竟未能明辨而仍处死。这是与蕲州授官不同的一次事件：前次分歧在官职出路，此次冲突还涉及军功归属和使者安全。奏报本身存在竞争，不能因为最后有斩刑就反推宋威报告全部得到证实。[^降]

## 878年荆南、黄梅及余众去向

878年正月，仙芝部陷江陵罗城而未尽下子城，李福率军来援，沙陀骑兵也参加。二月，曾元裕奏黄梅大胜，追斩仙芝、传首。所报五万余死者是奏报数字，尚无独立兵籍核对，不据此精确计算军众死亡率。尚让率余众归黄巢，巢获推戴、署官属，战争领导重组；另有王重隐、曹师雄等部继续转战。首领被杀没有终结所有起事网络。[^终]

## 后果与比较

王仙芝事件的特点，是灾荒动员扩大、流动战与多次招抚并行，最终由军事失败与军众转投完成阶段收束。与[庞勋](庞勋起事.md)相比，二者都涉及军众出路和赦命信用，但起兵制度位置不同。与[黄巢](黄巢战争与大齐政权.md)相比，仙芝没有经历占据两京、建立大齐的阶段，不能把后者全部活动倒写到前者名下。
