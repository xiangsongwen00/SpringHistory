# 银刀军兵变与武宁拆分（862）：牙兵、主帅和处置记忆

研究编号：EV-YD。范围：862年处置，前溯849年，后续至868年庞勋返途。本文将其称为军镇兵变；不能仅凭“起义”通称推定其与裘甫、王黄军众具有相同社会构成和诉求。

## 亲兵组织怎样成为主帅的约束

《通鉴》追述王智兴募勇悍者，设置银刀、雕旗等七军，以其中数百人轮值牙署。组织的最初用途包括护卫主帅，但当主帅更换而军众及其地方关系持续，保护力量也可能成为左右新主帅的人事力量。849年徐州逐李廓，卢弘止诛都虞候胡庆并安抚余众，已显示平乱与维持军府日常统率须并行；不能把862年当作毫无前史的一次突然暴动。[^旧]

军士待遇、犒赏与主帅的安全被系在一起。田牟与军士饮酒、唱歌等细节，在史书中服务于“姑息骄兵”的评价；但其中也能看见主帅不断以物资和亲近姿态换取承认。不能只写文臣软弱，还须追问主帅能否另掌可靠武力、军府怎样支付这些承诺。

## 862年驱逐温璋：安抚为什么未被相信

温璋以严厉著称，虽然到镇后安抚，军众却疑惧，连所赐饮食也不敢入口，七月终于逐帅。此处直接可见的是对人身安全的不信任，不是原文已经提供了一份全体军士共同认可的政治纲领。朝廷判断温璋无辜，将其移邠宁，改王式镇武宁。由此，驱逐一帅既改变当地人事，也迫使中央决定惩罚军众还是继续妥协。[^逐]

## 王式借外来军队执行杀戮

讨裘甫的忠武、义成军尚在浙东，朝廷命随王式赴徐州。八月，军众先因外兵到来而惧，王式视事数日后借犒送两镇军之机，命武装部队包围当地兵，银刀都将邵泽等数千人被杀。史书总称“尽杀”，后文又有逃匿、自首和庞勋招纳余党的记载，因此不能把它理解为所有相关者在同一天无一存活。[^杀]

两镇军不是中立的外部背景，而是使新主帅有条件摆脱本地牙兵胁迫的执行力量。短期内中央可以用兵镇压，长期却留下受害亲族、流散军人和对集体处罚的记忆。这一社会后果不能被“徐州遂安”四字抹去。

## 处分不止杀军：军区和属州同时被拆分

八月敕解释原置武宁为控扼淄青、光蔡，现因其反成乱阶，改徐州为团练、隶兖海；濠州归淮南，宿州另置宿泗都团练观察使，徐州留兵，其余分配他道。王式与监军杨玄质又负责安置将士后解散外援。这是领地、军额、统属及人员配置的组合调整，不是简单改一个官名。[^制]

## 868年的后续：银刀旧事如何进入庞勋事件

北返戍卒公开谈论罪重于银刀，怀疑朝廷赦免只为避免其沿路攻劫，到徐州仍将被杀。他们重新造甲兵，招集银刀逃匿者。徐州将吏则讨论此前歼夷流窜已有枉滥、再放返卒入城可能内外响应。彼此对同一处置记忆作出不同的安全判断，成为[庞勋起事](庞勋起事.md)的一项具体连接。它解释为什么一纸赦命难以消除疑惧，却不能把两次军众视为完全同一批人。[^后]

本事件的收束包括862年军众被杀和军区拆分；后续影响延至868年。用“牛李党争”并不能解释这一链条，军众组织、处置程序与亲属关系更直接。
