# 牛李党争：前因、冲突集中期与终结边界

研究编号：TH-NL。对象是特定阶段的人事排斥、政治关系与史学归类，不是历朝必备的“党争制度”。本篇把808年作为前因，文宗、武宗到宣宗初的斗争作为重点，860年的追复作为后续；这些层次不能混成一条始终不变的组织史。

## 为什么不能拿“二党”解释全部政治

牛僧孺、李宗闵与李德裕是传统叙述的关键人物，但交往、婚姻、同年、辟署和共同反对一人，并不等于近代政党式的固定成员资格。一个人与某人合作，也可能在其他事务上持不同意见。应先记录有时点和类型的关系，再讨论阵营，而不是先分党再删选史料。

## 808年：被追溯的前因

《通鉴》记牛僧孺、皇甫湜、李宗闵策试直言，考官列高等，李吉甫不悦，复审及考策官随后被处分；白居易又上疏论其不当。这里可以明确讨论直言策试、考官责任、亲属回避与宰相压力。李德裕尚不是这次策试冲突的直接主角，把父辈争议视为后来记忆和关系的一项来源，比声称808年两个固定政党已经成立更稳妥。[^策]

## 文宗、武宗时期：争相、政策与司法不能只有党名

三朝以外的文宗阶段是本专题前史，不能变成宣宗逐年年事。既有宣宗材料已提示会昌旧人与新相之间的关系；本文以844—845年两件可定位材料细化观察。昭义平定后，李德裕追究牛僧孺、李宗闵与刘从谏交通，史书记求书无获、又取证词，二人被贬。指控、证据取得与司法判断必须分别叙述，不能将史载指控自动写成已证通谋。[^会]

845年吴湘案又涉及盗用钱粮、婚姻身份、复审与是否交法司详断。被处分的复审官和谏争官有自己的程序主张，不能只作为某党人数计数。李德裕同时任用与牛僧孺有交往的柳仲郢，亦提醒所谓二党关系并非所有场合都以绝交为界。

## 846—849年：阵容逆转与当事人退出

宣宗即位后李德裕罢相，白敏中、令狐綯等逐步进入决策中心，吴湘案重审又扩大处分。具体程序与异说见[宣宗政治结援分论](../tang-xuanzong/专题研究/政治人物与结援.md)。能够确认的是李德裕及会昌时期相关官员的政治处境急剧变化；不能据此断言所有新任官员皆出于同一终身阵营。其后重要当事人离开政治中心、去世，持续性对抗失去原来的人员与职位基础。[^宣]

## 何谓结束，何谓余波

“结束”至少有三种判据：主要领袖能否继续争相；旧案是否仍被追诉或翻案；亲属、门生及婚姻记忆是否继续影响仕途。三者不会同时归零。860年刘邺请求哀恤李德裕父子，朝廷复官赠官，表明评价与追复仍可延续，但这不是二党重新组织对抗的充分证据。[^复]

因此不硬划一个所有层面同时停止的日期，也不无限延长。懿宗的杨收、韦保衡等关系、僖宗的郑卢用兵分歧，应先从当时任职、婚姻、请托和具体政策解释；只有找到实际承接关系，才讨论牛李旧事的影响。人物传记中可保留这一调查方向，目录不再要求每朝填写牛李党争。
