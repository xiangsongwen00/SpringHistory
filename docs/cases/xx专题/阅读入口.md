# 专题研究成果范式

这里把“xx专题”落实为可阅读、可核查的研究成果示例，而不是填空清单。[完整示例：监军如何改变一道军事命令](安南监军与奏报机制.md)采用真实史料，展示从问题、背景、材料、机制、分歧到结论的完整过程。

## 一篇成果需要交代什么

读者首先应知道研究对象、时空范围和核心判断。随后解释制度为什么产生、由哪些环节组成、不同参与者怎样行动，再以具体材料检验。制度名称和人物名单只供定位，不能替代过程。

正文必须回答：材料直接支持什么，作者怎样从材料推出结论，其他解释为何不足；异年和异文究竟影响哪一步判断。对能够讲清的背景应作实质说明，对资料不足只限定具体结论，不用泛泛的待考句结束全部讨论。

## 结构与表达

摘要与判断—背景与形成—材料与行动—机制与关系表—异说及解释—社会空间影响—结论与下一步。不同专题可调整段落；不按字数凑篇幅，也不把每条制度都写成兴亡单因。

注释提供书名、卷篇、原纪年、章ID、段号、查询日期和本机原文入口；出处记录补充SHA256及版本状态。对外正文保留必要短引，全文库、私有配置与现代校注全文留本机。
