# 黄巢战争与大齐政权（875—884）：转战、建政与晚唐格局重组

研究编号：EV-HC。以战争阶段组织叙事，区别首领经历、军众流动、占领与建政。880年旧历末入两京、改元的事件，本文沿史书年界标示，不自行换算公历日；不能用现代年末直觉处理旧历跨年。

## 875—877：响应、合兵与分兵

《通鉴》记875年黄巢于冤句聚众响应王仙芝，追叙私盐、任侠及应举经历。它们可帮助理解个人和交往背景，仍不足以给数万参加者规定统一职业。876年蕲州，王仙芝受官安排使黄巢及军众不满，双方分兵；877年又在宋州合战。关系有分有合，应逐次画出，而不是一条自始至终的垂直指挥线。[^起]

## 878—879：余众归附与南下的多个阶段

王仙芝黄梅败亡后，尚让率余众归巢，推立名号、改元、署官属，标志领导重组。黄巢也曾经由天平请求官职而未按要求解甲，继而向江西、浙东、福建转战，878年末陷福州。南下并不是一开始便已证实的“先取广州、再北伐”完整方案；各次受挫、受官谈判、追兵与供给压力都可能改变行程。[^南]

879年，张璘等击败部分军众，多名将领转降唐方。黄巢求天平、广州节度使未获准，九月攻陷广州、执李迢。唐方以市舶宝货为反对授广州的理由，说明广州既是海贸节点，也是朝廷不愿交付的财政资源。至于外文史料所载广州商人死难及人数，本轮尚未核读原文与译本，不用网络流传数字作已证结论，也不因未核数字就否认战争对居民和商贸的破坏。[^广]

## 879年末—880：湘江北还、江陵与渡江

岭南疫病迫使部众请求北返，黄巢自桂州制筏沿湘江北下，攻潭州，逼江陵。王铎移军后，刘汉宏部先掠江陵，城民又受大雪与逃散之苦；毁坏不能全部算在随后到来的黄巢军一方。880年黄巢在信州受张璘急击，假降、行贿和唐方遣散诸道兵使局势再变，张璘败死。黄巢攻宣州，经采石渡江、逼天长六合，高骈保守淮南，北上通道逐渐打开。[^北]

## 880年末潼关与长安：防线失灵不是一个将领的事

东都留守迎降后，唐廷命张承范等守潼关，分前锋、粮料、寨栅；齐克让军已缺粮，京师出军又有富户冒籍与雇贫人代行的记述。抵关时粮援未到、村民被征运石水，禁坑未守与前军饥溃共同造成防线崩坏。不能把失守只归于地形或一句“宦官不懂军事”，也不把所称数十万敌众当作精确兵额。[^关]

黄巢军进入长安时有安民宣告、向贫者施财，数日后又掠杀，不能截取其中一幕代表全部。黄巢在含元殿即位，国号大齐、改元金统，设宰相、枢密和翰林等官，分别处置唐官等级，确实进入建政阶段。但使用官名、仪物不等于各地已有稳定的税籍、仓储和行政体系；必须继续查谁任事、谁收粮、哪些州真正接受命令。[^齐]

## 881—882：关中争夺、联盟变动与民众代价

郑畋整合凤翔及邻镇，龙尾陂一战击败尚让等；关中各军仍非始终协调。王重荣先附齐，因不断征财征兵又拒齐；朱温从齐将到882年降唐，同样不能用不变党籍解释。大齐长期困在关中，兵源、粮源与周边军事支持不断变动。唐方复京联盟含多镇、内官与各族军众，内部也有结怨和功劳竞争。[^争]

双方对居民的代价都应呈现：掠粮、征兵、道路阻绝、反复城战和流亡，不能以唐廷的正统语言免除官军责任。新材料若只有将帅奏功，还须警惕居民经验被遮蔽，不能从“克复”推定市民立即安定。

## 883：复京后战争仍在继续

李克用受召，与河中及诸镇军协同，零口、渭南等战后入长安，黄巢沿蓝田、商山东走。官军入京同样暴掠，追兵又因争取遗财而迟缓。长安收复因此不是战争结束点。黄巢与秦宗权联兵，孟楷攻陈州被杀，引发黄巢长期围陈；赵犨以城防、移入资粮和家族将领组织守御。[^陈]

长期围攻使粮源破坏加深，史书载掠人食用及“舂磨寨”，应作为极端战争暴力叙述分析，不拿来描写通常饮食，也不把没有清查依据的恐怖数字再加工成统计。陈州及周边居民承受的不只是城破风险，还有被迁入、被掠走、征粮和断耕。

## 884：解围、追击、首领死亡与后续

李克用会诸军救陈，太康、西华失守使黄巢撤围；王满渡、封丘等战后军众溃散，尚让、葛从周等分别归不同唐镇。李克用追至山东后因人马疲乏、粮尽而返，又发生上源驿之变，复京联盟的冲突反过来塑造此后格局。卷256记六月林言斩黄巢、七月献首；首领死亡、首级送达和朝廷受俘应分别记，不将其合成一个日期。关于具体死法与地点，本文以《通鉴》为叙事底本，仍保留与其他记载进一步对校的空间。[^终]

黄巢覆败没有恢复战前秩序。朱全忠取得宣武、李克用取得河东，秦宗权的扩张仍持续，地方乡兵和投降将领进入新军镇。结论不是“所有藩镇都更强”，而是不同地区的旧组织崩解、新力量接手与中央协调能力改变；详见[方镇从唐到宋初的转型](方镇的形成与转型.md)。
