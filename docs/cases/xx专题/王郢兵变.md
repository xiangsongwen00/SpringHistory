# 王郢兵变（875—877）：军功、衣粮与海上武装

研究编号：EV-WY。范围：浙西起事至王郢被杀。它与王仙芝、黄巢同时发生，却不是二人的同名分支；相近姓氏及同时作战都不构成隶属证据。

## 职名为什么没有兑现为实际待遇

875年，狼山镇遏使王郢等六十九名有战功者，获授职名而不给衣粮，投诉不得，取库兵作乱，沿途收众，陷苏、常，以舟入海，掠二浙及福建。名义奖赏、军人日常供给与申诉渠道发生脱节，是材料中直接可见的触发机制。史书所谓近万人是扩张后的数量，不能当作最初六十九人的固定军额。[^始]

## 舟船流动与招抚条件

876年，朝廷设缘海水军讨之；王郢经温州刺史鲁寔请求投降，朝廷召赴京，王郢却拖延并要求望海镇使。朝廷授卫府官、拟在神策军补重职，并允许保留既掠财物，仍未解决其要求掌握地方镇兵的条件。这里区别名衔、实际兵权、军众安置和财产，才能理解双方为何没有仅凭一道除官终止战争。[^抚]

## 877年：人质、舟师与集团分解

王郢诱执鲁寔，攻望海镇、明州、台州，唐方发多镇兵及浙闽舟师。镇海裴璩一面守备，一面招降其党朱实，散众、收器械与舟航，削弱王郢组织。王郢余众到明州，甬桥镇遏使刘巨容以筒箭射杀之。结局是军事压力、分化招降和地方节点防御相结合，不是一场陆路追击包办所有。[^终]

## 地方后果

海上流动使本来分属不同州镇的军务与贸易相接，沿海居民、舟人和商货受到波及。董昌因土团讨王郢有功得镇职；此后杭州八都形成又与其他军众入浙有关。可以追踪地方乡兵获得任职与组织经验的过程，不能将后来的吴越政权说成王郢已经计划好的结果。与[裘甫](裘甫起义.md)相比，两事都涉及山海交通，却有不同的军事起点、组织和招抚要求。
