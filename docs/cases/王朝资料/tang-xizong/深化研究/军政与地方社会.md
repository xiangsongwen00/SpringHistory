# 潼关、成都与沙苑：军粮、觐见和联盟如何改变战局

研究编号：tang-xizong-R02。范围：本朝在位期，必要前后事件另标。更新日期：2026-10-24。原纪年月份沿旧历。

<a id="case-analysis"></a>

僖宗迁徙不是一串地名，也不能只用田令孜擅权解释。潼关的粮饷与防御、成都的君臣接触、885年两池盐利与移镇，分别显示军事能力、信息渠道和联盟资源怎样相接。

## 一、880年潼关：有任命不等于形成防御能力

《通鉴》记朝廷议守潼关，张承范、王师会、赵珂分别承担前锋、粮料和寨栅，田令孜及杨复恭居上层统筹位置。任命已经区分任务，但到关后增援、馈饷不足，齐克让军疲饿，村民又被征运石汲水。不能只从官职表推定防御系统已经有效运转。[^潼关]

所谓禁坑，平时以榷征税限制通行，仓促间失守，溃兵踏开通路。它说明关隘税路与军事地形相连；但直接写“税收导致潼关失守”仍过于简单，因为绝粮、军心、兵力和防守准备同时起作用。史书中的黄巢军总数也不作现代精确兵额。[^潼关]

## 二、881年成都行在：谁能确认皇帝安危

孟昭图疏关心的并非单纯争礼遇。他指出西幸不告南司、兵变时闭城不召宰相、次日又不得进见，百官无法确认皇帝情况；田令孜屏疏、矫贬及害之，则显示书面申诉渠道本身可能被阻断。行在虽有皇帝和朝廷名号，君臣接触却不自动恢复。[^行在]

叶炜2014年论文以德宗朝陆贽为主要对象，考察奏状流转与信息差异。其方法可用于追问此案的接触和报告机制，不能将其前期制度结论逐项当作881年的已证流程。[^研究]

## 三、885年盐利与移镇：调任为什么会变成战争

田令孜欲以两池盐利供禁军，王重荣以本镇军费抗辩。继而移镇命令触及地方军众与收入控制，王重荣转而依靠李克用，沙苑之战又导致皇帝再迁。盐利、任命与军事联盟应依次解释；两史“全隶神策”与通鉴“归盐铁以赡军”的不同表述也不可合成同一机构归属。[^盐利]

## 四、887年王建与田令孜：养子并非无条件服从

田令孜以养父关系召王建，陈敬瑄后来悔而拒其进入，王建遂以进退失据为由发兵。材料同时记王建自身又有假子部众。这表明收养关系可以组织信任与期待，却未消除各方军事利益；不能一见养子名号就把所有部队画成完全受养父掌握的层级。[^王建]

## 结论

从潼关到行在再到沙苑，决定能力的不是命令是否写下，而是粮兵是否到达、信息能否流通、军众是否接受及财源如何分配。解释这些条件，比只重复“中央衰弱、藩镇强大”更能说明各次转折。
