# 唐僖宗：科举

专题编号：XZ-C07。整理日期：2026-10-23。范围：乾符至中和；唐彦谦等生平宽年代。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

## 材料与叙述

《旧唐书》叙唐彦谦咸通末举进士、十余年不第，乾符末避地汉南，中和中受王重荣辟为河中从事。此例将举业失利、战乱迁徙和军镇幕府聘任连接起来，不意味着战时科举一律停止。[^一] 《北梦琐言》记士人对与内官交游的避忌及乐朋龟、张濬与田令孜公开礼敬，适宜研究声誉规范，不视作正式科举禁令。[^二]

## 从制度背景解释本朝个案

唐彦谦避地汉南、入河中幕府，皮日休又见任职大齐，显示战乱让士人的政治依附与就业地理重组。这里应继续核作品与职期，而不先用最终政权归属给整个人生作单一评价。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《教育、贡举、铨选与关系网络》](../../../背景综述/晚唐时期背景综述/科举.md#background-mechanism)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

科举既提供可共同评价的文字标准，也生产师生、同年和礼仪关系。它不能被写成完全排除门第的公平机器，也不能被缩成权贵私相授受。研究应追踪不同环节如何打开或限制具体人的机会。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
