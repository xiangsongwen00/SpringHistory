# 唐僖宗：边患、兵变、起事与并行政权总览

范围：873—888年。总览提供入口，完整事件的路线、战役、招抚和社会后果分别见专题，不再以数句概括王仙芝、黄巢战争。

## 王黄战争的阶段关系

874年王仙芝初聚众与875年黄巢响应先后不同；876年分兵后又有877年合战，878年王仙芝死，尚让率余众归巢，不能把两首领视作固定的上下级。黄巢879年广州、880年北渡和两京、881—883关中建政争夺、883—884陈州至山东，又各有不同的粮源、军队和居民处境。城破、改元、复京、首领死亡及献首不在同一时点，详见两篇专题。

## 西南的战争、议和与礼仪争执

875年高骈赴蜀后，南诏军退，唐方修关堡，并讨论是否追击。877年酋龙卒后南诏与唐议和，唐方减少邕州客军，双方都承受长期战费。879年徐云虔出使又牵涉兄弟、舅甥、称臣奉贡等名分，880年唐廷在军事困局中同意进一步议和。它们是有自身君主与政治诉求的政权关系，不能写成一串“起义”；称谓的协商本身也是政治实践。[^南]

## 代北军众与唐廷：结盟不是族属的自动结果

李国昌、李克用一度与唐军及其他部落军作战，败后入达靼；后来被召参与复京。河东、沙陀、吐谷浑、达靼等既可合作，也会分裂，并非每个人依据单一族属选择阵营。李克用得到河东后与其他军镇的关系又变，上源驿冲突即提醒复京联盟并未消除政治竞争。[^北]

## 平民、土地与城市不能只作战场背景

粮运中断、军队换隶、招降与反复征发改变当地生活。江陵先遭唐将部众掠夺，长安复京后官军亦暴掠，成都突将案有老幼牵连，阡能平定后又有地方官借追党图田；都须分别归责，不能把一切破坏归于一种军队。各事件专题保留这些具体环节，不由“农民起义”“藩镇割据”两个名词代替。
