# 唐僖宗：行政区以及土地政策、流民政策

专题编号：XZ-C04。整理日期：2026-10-23。范围：873—888；灾荒、战争与迁徙。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

<a id="case-analysis"></a>

## 材料与叙述

关东饥荒、黄巢军转战、长安反复易手与扬州围困，使逃亡、就食、军众流动与官僚避难并存。《通鉴》记复京官军暴掠，说明人口回流与土地复耕仍受暴力影响。[^一] 皇帝从长安至成都、又经凤翔至兴元的路线，则是行在迁徙，不能与一般流民合并统计。[^二]

## 人物、制度与空间关联

地理分册按政区、军镇、治所与暂时占领分层。田宅产权、军粮占取、地方招复和移镇命令分别建档；文学家入幕与避地可补精英迁徙路径。

参[编年纪事](../年事/编年纪事.md)、[本纪与人物群体](../纪传体/本纪与人物群体.md)、[历史地理](../古地理与行政区划/历史地理.md)。同一事件沿用原编号，专题编号用于研究归类，不另算一次历史事件。

## 合论与证据边界

现有材料不足建立全国土地再分配政策或连续人口数据库。战争饥民的食物记载不代表常态生活；政权恢复与地权恢复无直接等式。

## 从制度背景解释本朝个案

长安、扬州的反复战争与行在迁移让各类人口走上不同道路。研究精英避难、军众转移和普通居民流亡时，应分别寻找任官记载、军事路线和生计材料，不能以文人有去处证明全体流民获安置。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《土地、户籍、辖境与人口流动怎样相接》](../../../背景综述/晚唐时期背景综述/行政区以及土地政策、流民政策.md#background-mechanism)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

土地人口研究需要把权利与责任放在同一时间和地点：谁耕、谁有田、谁纳税、谁受保护、谁能离开。对古今地名只做经核实的对应，尚不清楚的古道路和边界不画成精确线。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
