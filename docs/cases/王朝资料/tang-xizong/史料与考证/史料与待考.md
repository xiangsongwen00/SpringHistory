# 唐僖宗：史料、异记与待考

整理日期：2026-10-23。依据本机《旧唐书》《新唐书》《资治通鉴》相关原文；实际读取范围及来源哈希见[出处验证记录](出处验证记录.md)。

| 编号 | 问题 | 本轮实际证据与处理 |
|---|---|---|
| D-X01 | 王仙芝起事何年 | 《通鉴》874年末书初聚众，875年记攻曹濮及黄巢响应；两《唐书》主要在875年叙攻州。区别初聚众与扩大作战，不机械写成单个年份相互否定。 |
| D-X02 | 李克用杀段文楚年次 | 旧纪卷十九上提前系于咸通十三年十二月并接十四年；新纪及《通鉴》卷253系乾符五年，即878。主表采用后两书，保留旧纪异记，不改写数据库。 |
| D-X03 | 广州陷落月份 | 本机两《唐书》系879年五月，《通鉴》卷253系九月。围城、求官、告身与陷城各节点需重新逐段对校，现稿不强配日期。 |
| D-X04 | 黄巢死亡与献首 | 《通鉴》卷256六月叙败亡，七月献首；新纪七月书伏诛。主表分列死亡、消息和献首，仍须校相关列传，不据“伏诛”假定七月才死。 |
| D-X05 | 到成都、复京及再播迁 | 原纪与新纪对成都到达的编排不同；883复京与885皇帝返京是两件事，885—886再迁又是另一轮。路线、月日不混写。 |
| D-X06 | 文学人物的政权任职 | 皮日休受大齐任职有主干史料，但动机、作品、结局仍待文集及传记对校；不据受职即作价值判断。 |

上述证据见《旧唐书》卷十九上段105—106、十九下段59、77—83、124、158—160；《新唐书》卷九段23、26、32、40、42、44、52；《通鉴》卷252段90、107，卷253段38、85，卷254段22，卷256段7、9。[^异记]

## 下一轮补证

- **土地、逃户与经济**：核灾荒蠲免的实际执行，征敛、义仓、盐铁和军费分别建表；尚无人口或地权变化的可靠全域量化结果。
- **方镇与世家**：逐传查郑畋、王铎、崔安潜、王重荣、高骈、朱全忠、李克用等，记录亲族、婚姻、牙兵、养子和任官来源；不预设全都属于牛李党争余波。
- **文学与诗歌**：补皮日休、陆龟蒙、杜荀鹤、韦庄、罗隐等的具体作品、纪年和行迹；此名单是检索计划，未核的作品系年不进入主年表。
- **社会生活、酒曲和科技**：上源宴饮、饥荒食物和朝廷仪礼已有场景材料；常态饮食、酱醋茶、柴薪、酒曲与酿造、民间服饰须查同时期文本及物质资料，不能以战争饥食替代日常生活。
- **多政权与族群**：唐、大齐、煴政权、南诏及各地军镇按组织层级区分，沙陀、回鹘、吐谷浑、达靼按具体材料识别，不拿晚唐至元的一般框架抹平时期差异。
- **地理志与方镇表**：下一步逐核州县隶属、置废、交通节点；目前历史地理稿来自已读行动材料，不是完整单年行政区划数据库。
