# 唐宣宗时期年事与历史地理：第一轮整理

整理日期：2026年10月19日。性质：有出处的研究初稿，供继续检索、校勘和建库使用；不是全量史料汇编或定稿年谱。

## 范围与使用方法

本稿以唐宣宗在位为主体：会昌六年（846）三月即位，至大中十三年（859）八月去世。大中元年为847年。859年八月以后虽仍用大中年号，已属懿宗即位后的政事；大中十四年（860）也不属宣宗在位期。末年交接和具体卒日，各书记载有出入，暂按“859年八月”处理。

“年事”包括政局、军事、灾荒、赋役、交通和制度；“历史地理”重点记录收复、改置、隶属、军镇驻地、交通营田与地方社会变化。所有月份均为史书旧历；没有进行公历月日换算。公元年仅供年度检索，不能直接与公历1月1日至12月31日重合。

先读 [年事初表](../年事/编年纪事.md)，再用事件编号查 [历史地理初表](../古地理与行政区划/历史地理.md)。两表共用出处代号；具体链接和争议说明见 [史料与待考](史料与待考.md)。按用户补充意见，以《新唐书》《旧唐书》《资治通鉴》为主干，地理以两书地理志为骨架，相关表、传及《唐会要》等用于补证。

本轮成果包括54条在位期年事、1条界外续事、9条地理志补录（其中Z04是N11置州异说，不独立重复计数）、14组州县关隘变化条目及军镇道路专题。原文锚点35条，待考事项13项。

根据后续要求，已另建[纪传体专题稿](../纪传体/本纪与人物群体.md)，按本纪、表、志、列传与合论组织，涵盖皇帝、大臣、文苑诗人、商人盐贩、流民、土地、经济、地方管理与监督、家族门第和宦官。另建[本朝政治人物与结援](../专题研究/政治人物与结援.md)，作为贯穿各篇的主线；依据与争议见[纪传体史料补记](旧稿史料补记.md)。本轮新增B01—B14共14条编年补录（含宽年代材料及与原条互证者），保留N、Z编号以便两种体例互查。

本轮还抽核两书有关列传、《新唐书·食货志》及方镇表相关列。发现《通鉴》859改隶大同的记载与方镇表843分出三州、844升防御的关系待考，已修订原N52，不再将859称作确定的首次分置。

新增[边患、起义与多民族政权发展专题](../文化制度以及影响研究/边患、起义与多民族政权.md)。将晚唐至元作为多民族政权并行、竞争、交往与融合发展的比较范围；当前已落实的是宣宗时期案例分类及长时段研究框架，不是已经完成晚唐至元全史。政权内部发展、战争与起事、贸易迁徙、婚姻宗教、制度文化交流均纳入，区分古代族称、政治归属与现代民族名称。

新增[科技、物质生活与礼俗专题](../文化制度以及影响研究/科技物质生活与礼俗.md)，纳入服饰、礼仪民俗、饮食、柴米油盐酱醋茶，单列酒曲酿造、酒政与酒文化，并与生产技术、商业、财政、军需、身份和跨区域交流相连。当前为专题框架及W01—W08首批线索，不冒称已经完成全部生活史考证。

## 当前最有价值的研究线索

1. **849—852年的西北经营**：三州七关收复后，紧接着有武州、威州改置、秦州隶凤翔、秦成经略、营田、盐利、流人安置及关堡道路政策。把军事收复与后续行政经营连起来，比单列“河湟收复”更能说明地理变化。
2. **沙州归义军与十一州图籍**：851年置归义军有明确记载；具体州境控制程度、伊西等州的归属与时间，需要敦煌文书和地理志补证。本稿保留传统史籍用语，同时避免据此绘制统一、稳定的实控疆域。
3. **边军与地方社会**：851—855年党项地区的授闲田、给复、军镇移驻和复归，是观察军政区与人口土地关系的材料。
4. **江淮至关中的运输**：裴休漕法与855年淮南饥荒、减馈运、蠲租相联系，适合形成漕运和财政地理专题。
5. **857—859年的南方军乱与安南防御**：容管、岭南、湖南、江西、宣歙接连出事，不能只凭“大中之治”的总体评价省略地方不安。
