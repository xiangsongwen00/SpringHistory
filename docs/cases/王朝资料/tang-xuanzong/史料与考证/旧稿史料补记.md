## 原文锚点与解释限度

| 编号 | 定位与原文短摘 | 解释限度 |
|---|---|---|
| K01 | X54：“宣宗即位，茶、鹽之法益密”；私盗多者处分观察、判官“不計十犯”。 | 这是史志对一段政策的概述，无确切月日。 |
| K02 | X54周墀条：“迹其居處，保、社按罪”；并列不同贩卖、买入及亭户盗售数量和死刑。 | 奏言与实际刑案区别保存；不得把“保、社”直接套作明清保甲。 |
| K03 | X54：“鎮戍、場鋪、堰埭以關通致富。” | 可研究监管失效与交通节点牟利，但未列各节点人数、所得或具名经营者。 |
| K04 | X54：“裴休……上鹽法八事”；J190下司空舆段：“特定新法十條奏之”。 | 两者是不同人的不同措施，不因为条数相近就合并。卢弘止、卢弘正等姓名异文须校。 |
| K05 | X182裴休：“許收邸直，毋擅賦商人。” | 限制额外横征，不等于废除合法税收与收费。 |
| K06 | J177漕法段：“悉令縣令兼董漕事”；“巡院無得侵牟”。 | 体现职责与资源调整；绩效数字尚需别证。 |
| K07 | X182裴休：“請宰相人自為記，合付史官。” | 建议留存不同宰相的政务记录；不直接称现代政务公开。 |
| K08 | X182李珏：“江淮旱，發倉廩賑流民”；末年称“神策軍常為豪商占利”。 | 年月未明；不能把豪商一概判为私盐贩，也不能把神策军等同所有宦官。 |
| K09 | X167王式：“會河曲大歉，民流徙，佗州不納，獨式勞恤之，活數千人。” | 系“大中中”，不硬定某年；“数千人”是传述数字，非本轮重建统计。 |
| K10 | J190下李商隐：“大中初，白敏中執政，令狐綯在內署，共排李德裕逐之。” | 是传记的政治解释；与处分制书、本纪并读。 |
| K11 | J174：“及德裕失勢……同謀斥逐”；J172牛僧孺段又褒其进退。 | 同书不同传的褒贬取向也可能不同，不把整部书简化为单一立场。 |
| K12 | J190下温庭筠：“大中初應進士”；继叙“咸通中”广陵事。 | 同一传中的事件跨朝，不能连段搬入宣宗年事。 |
| K13 | X64大中五年：陇州置防御使、领黄头军使；邠宁“增領武州”。 | 表的列位置必须核对，避免串到邻镇。 |

## 本轮新增待考

**C11：茶法条数与制度时间。** J177裴休传作税茶法二十条，X182作十二法；X54又载大中初条约。分别存原文，不认定三个表述完全同一版本。漕运十条与盐法八事、司空舆十条也不合并。

**C12：卢弘止／弘正、司空舆。** X54记卢弘止遣巡院官司空舆改法，J190下司空图传前叙作大中初卢弘正领盐铁、奏其父司空舆任两池榷盐使。官衔与名字须版本校核；现阶段仅能确认两处均载司空舆参与盐法调整，不统一造一套精确履历。

**C13：李珏与神策军豪商税酒案。** X182把事件叙于李珏晚年；J18载852卒，可暂限于宣宗初至852，不能指定某月。传称尚未收到奏报回应，不能写为李珏已成功夺回税源。

**C14：大同三州改隶。** T249记859三月，X65记843分三州置团练、844升防御。可能涉及不同阶段、恢复后再调整或记年问题；本轮材料不足裁定。旧表N52已追加提示，不继续写成确定的859首次设置。

**C15：方镇表后事附叙。** X64将邠宁内附后复旧治附叙在849行，T249将还邠州具体记于855。不能机械按表行把后事全部系于849。

**C16：白居易卒年。** 本轮见J166记“大中元年卒”，与常见846纪年有异；须对墓志、文集编年及他本。未裁定前不取此字面，把其整个大中活动延展下去。

**C17：控诉与证实。** 令狐滈受贿、干预科举、参与储位等材料包含宣宗死后提出的指控和自辩。每项应另设“被指行为日期、提出指控日期、调查／裁决、史家评价”。本轮不能视为均已证明。

**C18：匿名群体的主体性。** 盐商、亭户、流民往往在官府禁令和官员传中以集合出现。后续宜从文书、契约、墓志、诉讼和地方记载寻找姓名、家庭、成本与行动；缺材料就保持群体条目，不杜撰代表性个人。

## 后续检索顺序

1. 牛李：两书李德裕、牛僧孺、李宗闵、白敏中、令狐绹及相关附传，《通鉴》同年互校；按任免、案件、婚姻、幕职、制书分类。
2. 方镇：X64—X69全部相关列，结合宰相表、地理志、节度使列传；区分辖属、驻地、人选、实际到任、驻军和税源。
3. 财政土地：两书食货志与《唐会要》田制、户口、赋税、漕运、盐茶、逃户等条；记录制度实行与个案效果。
4. 文苑：两书文苑及官员附传先定履历，再校文集、碑志和作品系年。作品中地名、价格和社会形象需辨修辞与实指。
5. 地方监督：御史、谏官、给事中、监军、使院、录事参军、吏胥分别查；不能只收“直臣”成功故事，也收奏疏不报、执行受阻和失察处分。
