# 郑光庄吏、漕运与寺院：宣宗朝资源分配的不同边界

研究编号：tang-xuanzong-R03。范围：本朝在位期，必要前后事件另标。更新日期：2026-10-24。原纪年月份沿旧历。

<a id="case-analysis"></a>

宣宗朝的经济政策应把征收规则、执行谈判和资源用途合在一起看。皇帝承认一个原则，不表示对亲属的优待自动停止；财政收入增加，也不表示生产者与消费者的处境同时改善。

## 一、郑光免税与庄吏欠税是两件事

《通鉴》记皇帝欲免郑光鄠县、云阳庄税役，中书门下以统一税役原则反对，皇帝接受。其后又记韦澳任京兆尹，拘系郑光庄吏追征积欠，皇帝先问能否顾念郑光，后同意杖责、征足而释。前件讨论合法豁免是否适当，后件讨论积欠如何追缴和惩罚，不能合并成一次执法故事。[^庄园]

庄吏并非没有行动能力：其依附权贵、长期欠赋、扰害闾里，使私人经营与地方公权发生交叉。韦澳也并非完全独立于皇帝，而是在延英奏对中坚持原则、接受减免死罚并完成征税。材料显示的是有交涉的执法过程，不能简单评成绝对法治或完全无法无天。

## 二、漕运整顿怎样连接地方官考课与京师粮食

《食货三》叙裴休使河濒县令董漕，江至渭运输数量在三年总叙中增加。它提示漕运不仅是开河和造船，还涉及谁负责押送、运输损耗如何核算以及官员升迁怎样奖励。这里的三年成果不能算为某月收成，更不能直接当作全国农业产量。[^漕运]

## 三、茶盐刑禁与冶利：不同群体承担不同成本

《食货四》分列私盐、茶园户、雇载、居停侩保和场铺堰埭的责任，又叙河湟戍兵衣绢需求推动山泽之利归盐铁。这些材料把边军、财政官、运输节点与普通生产经营者连接起来。对一方减少横征，可能同时对另一方加重刑禁；研究不宜用“重商”或“抑商”一词覆盖所有人。[^专卖]

## 四、寺院恢复：政策转向不只是一笔经济账

846—847年的寺院恢复有场所和条件，不等于会昌没收的全部财产自动返还。李熙2016年论文摘要提出应把信仰因素与政治、人事合看。本篇据此避免只从财政解释崇佛，但不据摘要断定宣宗某次行为的唯一心理原因。[^研究]

## 结论

庄园、漕运、专卖和寺院各有规则，统一主题是资源经过何人之手、以什么理由改变用途、哪些人能够申诉。宣宗能纠正部分特权，并不证明这些矛盾已被一次解决；这些个案也不足以单独否定全部治理效果。
