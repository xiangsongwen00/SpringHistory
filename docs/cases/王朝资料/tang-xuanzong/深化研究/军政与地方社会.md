# 三州七关如何从归附变为经营：军政、户籍与交通

研究编号：tang-xuanzong-R02。范围：本朝在位期，必要前后事件另标。更新日期：2026-10-24。原纪年月份沿旧历。

<a id="case-analysis"></a>

849年的意义不能仅概括为地图扩大。本篇区分归附、朝廷应接、军队接收、州县隶属和长期经营，说明兵力进入之后仍需生产、户籍与道路支持。政治声望和经营条件是两个相接的分析层次。

## 一、把849年拆成多次行动

原年表N08—N16保存两《唐书》《通鉴》的不同月份。来降不等于接收已完成，朝廷遣使与边镇出兵又是不同动作；秦州、原州、萧关等处也并非同日全部移交。各书记月不同，不能为了编成一条顺滑叙事就删去差异。[^接收]

## 二、收复之后为什么还要免税、给种与定籍

《旧唐书》大中三年八月制把垦田五年免税、之后重定户籍、营田牛种、戍卒加给及替换、盐利和关堡道路放在同一经营方案中。它说明朝廷所面对的不只是守住城关，还有人口如何留下、粮食从哪里来、驻军能否长期维持。[^经营]

| 措施 | 直接对象 | 制度问题 |
|---|---|---|
| 垦田免税、后定户籍 | 新经营土地与居民 | 初期生产恢复与未来赋税承接 |
| 给牛种、营田 | 军镇及耕作者 | 农业投入与驻军粮源 |
| 戍卒给养及替换 | 驻防军人 | 长期守边与军人家庭联系 |
| 盐利、关堡与道路 | 财政及交通节点 | 经费、转运、安全与往来 |

这张表把制文解释为一个政策组合，不据此推定各项都按额完成。研究下一步应追踪哪些州有实施文书、谁成为纳税户及道路能否持续通行，而不是重复“边地经营待考”的总句。

## 三、区划与名号为何不能代表同一种控制

清水曾因秦州未复而暂隶凤翔，秦州又有迁治、军政隶属及经略称号的变化；武州设置存在本纪与地理志异年。沿用Z01—Z04等编号，是为了把治所、辖县、边镇隶属分表。851年归义军的图籍、节度使与观察名号亦应照此处理，不能从称号覆盖范围直接推定全域稳定实控。[^地理]

## 四、对内政局与对外经营的联系：怎样使用新研究

李军2021年论文的学院介绍把三州七关经营与宣宗政治声望、继承宪宗的表达联系起来。本篇把它列为解释方向，尚未取得该文完整论证，不将动机判断作为既定事实。[^研究]

本地史料可以先完成两步：比较制文怎样陈述祖宗、失地与民生，再检验真实措施是否支持长期经营。政治象征与实务可以同时存在，但不能因为有政治收益，就认定田地、牛种和驻防全是无意义的装饰。
