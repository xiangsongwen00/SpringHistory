# 唐宣宗：市场货币或者纸币

专题编号：DX-C06。整理日期：2026-10-23。范围：846—859；飞钱另标前朝背景。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

<a id="case-analysis"></a>

## 材料与叙述

《食货四》在会昌铜像钟磬铸钱之后，叙宣宗即位后新钱复铸为像。此处是佛教政策、铜料与钱币之间的叙事，不能把史臣“尽黜会昌之政”扩成每项制度均有独立废令。[^一] 同志“飞钱”叙事主要在宪宗朝，指异地合券取钱的安排，只能作为汇兑背景。[^二]

## 人物、制度与空间关联

市场交易需分铜钱、布帛折纳、计价与汇兑信用。军府和使司介入商业的前朝材料只作比较，不能直接生成大中朝统计。

参[编年纪事](../年事/编年纪事.md)、[本纪与人物群体](../纪传体/本纪与人物群体.md)、[历史地理](../古地理与行政区划/历史地理.md)。同一事件沿用原编号，专题编号用于研究归类，不另算一次历史事件。

## 合论与证据边界

当前没有核得本朝发行纸币的材料；飞钱不等于后世国家纸币。币种流通范围、钱荒程度、汇率与市场价格须查本期实物及文书，不据文件名写“纸币制度”。

## 从制度背景解释本朝个案

会昌铸钱及宣宗复铸为像的叙述，提供宗教器物与铜料流向的联系，但不能直接等同全国旧钱退出流通。将钱币实物、政策文字与市场使用分开，才能解释政策转向的实际范围。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《铜钱、布帛、估价与汇兑信用》](../../../背景综述/晚唐时期背景综述/市场货币或者纸币.md#background-mechanism)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

当前材料支持将飞钱、便换列为信用与异地支付研究，支持分析铜钱与实物的财政换算；尚不支持宣称三朝已建立国家流通纸币制度。这个判断来自支付机制的辨析，并非以“尚待考证”回避货币史。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
