# 唐宣宗：行政区以及土地政策、流民政策

专题编号：DX-C04。整理日期：2026-10-23。范围：N12、N19、N22；B06—B07；Z01—Z09。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

<a id="case-analysis"></a>

## 材料与叙述

849年河陇经营将垦田、牛种、戍卒替换与户籍结合；“五年内不加税赋”、其后重定户籍为永业，是收复地政策表达。851年党项安置有银夏授闲田、沿边给复等措施。[^一] 晋州王式收纳河曲流民与他州拒纳的传记材料，另提供地方接收能力问题，系“大中中”而非确定某月。[^二]

## 人物、制度与空间关联

区划、治所、军镇隶属、土地占有与人口身份分表。灾荒流民、逃户、边地归附人口、徒流罪人、军屯户不能混算。

参[编年纪事](../年事/编年纪事.md)、[本纪与人物群体](../纪传体/本纪与人物群体.md)、[历史地理](../古地理与行政区划/历史地理.md)。同一事件沿用原编号，专题编号用于研究归类，不另算一次历史事件。

## 合论与证据边界

“永业”不能据字面推成全国恢复均田。受田面积、户数与安置后赋役实绩未核；州县新复也不证明全辖区稳定实控。

## 从制度背景解释本朝个案

849年收复地的免税、牛种与军戍轮替是一整套经营安排。其目的不只是鼓励开荒，还要解决守边粮源与长期定居；“名义收复”与田地可持续耕作之间，必须经过道路、供给和人口安置。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《土地、户籍、辖境与人口流动怎样相接》](../../../背景综述/晚唐时期背景综述/行政区以及土地政策、流民政策.md#background-mechanism)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

土地人口研究需要把权利与责任放在同一时间和地点：谁耕、谁有田、谁纳税、谁受保护、谁能离开。对古今地名只做经核实的对应，尚不清楚的古道路和边界不画成精确线。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
