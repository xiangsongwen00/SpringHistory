# 唐宣宗：盐铁酒茶矿

专题编号：DX-C05。整理日期：2026-10-23。范围：B02—B03、B05、B07；W04—W06；大中时期。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

## 材料与叙述

《食货四》载宣宗盐禁益密，以官盐销售和私盗多少考核观察、判官，并有保社连坐；裴休盐法八事与两池课增相联。茶法区别园户私售、雇载、居舍侩保及成群武装经营，不能将所有违法者都写成盐贩。[^一] 同志叙河湟戍兵衣绢增加后，裴休请山泽之利复归盐铁；冶场数量是特定叙事口径，非本朝逐年产量表。[^二]

## 人物、制度与空间关联

盐池—交通场铺堰埭—商人—基层保社，与盐铁巡院及观察判官共同构成征收监管链。酒利参科技物质生活中的W04—W05。

参[编年纪事](../年事/编年纪事.md)、[本纪与人物群体](../纪传体/本纪与人物群体.md)、[历史地理](../古地理与行政区划/历史地理.md)。同一事件沿用原编号，专题编号用于研究归类，不另算一次历史事件。

## 合论与证据边界

盐、铁、酒、茶、矿并非同一种税法。财政增收不等于生产者获益；官盐数量、私盐判例、矿工处境、酒曲工艺及地方差别仍缺。

## 从制度背景解释本朝个案

宣宗财政整顿兼有限制地方擅赋与强化茶盐刑禁。合法商旅减少沿途乱收，与无合法渠道者面对更严惩罚，可以同时发生；所谓利商或抑商必须先说明是哪一群商人。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《专卖、征税、生产与军费的不同联系》](../../../背景综述/晚唐时期背景综述/盐铁酒茶矿.md#background-mechanism)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

本专题可确立的主线是：财政需求通过交易规则、官吏考核和刑罚影响日用品流通，再通过生产户、商人和军府的应对改变执行。研究成果应同时写政府收到什么、其他群体承担什么，不能以“榷课增”代替社会福利判断。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
