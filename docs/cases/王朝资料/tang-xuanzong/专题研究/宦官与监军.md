# 唐宣宗：宦官与监军

专题编号：DX-C01。整理日期：2026-10-23。范围：846—859；前期沿革另标。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

<a id="case-analysis"></a>

## 材料与叙述

### 身份、职掌与制度背景

“宦官”是身份，不能直接代表同一种职权。《新唐书·宦者上》分述内侍省五局的宫嫔簿籍、门禁、疾病死丧、供帐灯烛与中藏给纳；神策军中尉掌禁兵，枢密参与旨意传达，外镇监军介入特定军府，临时宣慰敕使又须逐次查明任务。职名、兼任和实际掌握的兵、印、奏报渠道均须分别记录。[^制度]

《唐会要》追述贞元十二年置护军中尉监，又在贞元十一年条记河东监军铸印；宝应元年条要求诸道凭正敕执行，不得只信中使口宣。这些是前期制度背景，不能写成本朝新创。其“始用中官”的追述仍需与其他制度史料核对。[^沿革]

### DX-M01 · 850年：马植与马元贽的宝带

《通鉴》大中四年四月叙，宰相马植与左军中尉马元贽叙宗姓，收受御赐宝带，朝见被宣宗识出；罢相后，亲吏被交御史台审讯，马植再贬常州。这里同时有宰相依附、宫廷赏赐、人事处分和外部司法核查，并非只有“宦官专权”四字。叙宗不能直接当作已证血缘。[^宝带]

### DX-M02 · 855年：浙东失律，监军并坐

浙东军逐李讷后，大中九年九月李讷被贬，监军王宗景杖四十、配恭陵；诏称“自今戎臣失律，并坐监军”。这是一条把监督者纳入责任追究的明确材料，仍不能仅据诏令推定此后每次均执行。[^并坐]

### DX-M03—04 · 奏报与继承的控制

《通鉴》在855年的总叙中记枢密承旨孙隐中擅改度支文字而获罪，并记韦澳对中使口宣要求御札；856年王归长、马公儒复奏萧邺新命是否罢度支，宣宗疑其袒护而改任崔慎由。书面文书与口头旨意的认证，是皇帝、枢密与翰林之间的具体权力环节。[^奏报]

859年八月，病中储位争议涉及枢密使王归长、马公儒、宣徽南院使王居方、右军中尉王茂玄与左军中尉王宗实。拟将王宗实外调淮南监军，既是任官也是调离禁中；亓元实劝其入见，继有迎郓王、杀三使等行动。这说明日常处分内官与控制继承不是同一层面的能力。[^继承]

## 合论与证据边界

宣宗可惩处内官，并不意味着取消监军或收回全部禁军权。现有材料以朝廷叙事为主；监军院日常经费、属员、地方百姓申诉与处分执行率仍缺。

## 从制度背景解释本朝个案

宣宗惩处王宗景时，把地方军乱责任延伸到监督者；其方式是以皇帝裁断和处分维持监督链。859年却仍须由宫门、枢密和中尉的实际行动决定继承结果。因此“能罚内官”与“有稳定的继承制度”不是同一结论。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《宫廷使职怎样进入地方军政》](../../../背景综述/晚唐时期背景综述/宦官与监军.md#background-mechanism)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

研究结论是：监军不是一个恒定的“监督官权限包”，其实际作用由皇帝授权、驻军、文书渠道、财源和当地联盟共同决定。宣宗朝的并坐、懿宗朝的合作分兵与截报、僖宗朝的杀帅署官构成不同运作方式，不能合并为权力一直线扩张的故事。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
