# 唐懿宗：边防、军镇与财政（859—873）

整理日期：2026-10-23。核验状态：本机数据库原文已读取；逐字校勘、原版页码、底本出版信息仍待补。数据库的 `decoded_unverified` 状态保持不变。月份用旧历，不转换公历日。

本案例从大中十三年八月即位，整理到咸通十四年七月去世及僖宗接位。即位在859年，咸通改元在860年十一月；“咸通元年”不是整个统治的开始。[^起讫]

本轮已形成40条编年事项、15个年次入口，围绕南诏与安南战事、徐州军镇及庞勋事件、财政供给、逃户赋役和皇位继承展开。起事军、中央军及地方军镇的多方暴力都按具体原文记载，不把史书的“贼”“蛮”直接当作现代身份说明。

分期为本稿的研究安排：859—862看继承、浙东与岭南建置；863—867看安南战事、海运和财政；868—870看戍卒起事及两线战争；871—873看地方治理、流亡税负和继承。它不是史书已有的统一分期。

[^起讫]: 《旧唐书》卷十九上《懿宗本纪》，篇首、咸通元年十一月、十四年七月；《新唐书》卷九懿宗部分，段3—4、17；《资治通鉴》卷249、252相关即位及崩逝条。本机录入本，相关正文已读，底本版次和页码待核。[查本机原文](hanji://J19上?q=懿宗)；[新纪](hanji://X9?q=咸通)。
