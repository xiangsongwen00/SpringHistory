# 唐懿宗：边患、兵变与起事总览

范围：859年即位后至873年。总览只梳理时间、空间与问题，详细过程进入独立专题。大中十三年十二月已是懿宗在位，不因沿用旧年号归到宣宗。

## 南诏战争与本地政治：不是一幅静止的族群地图

860—863年安南多次失守，须把南诏进兵、唐方对当地首领的处置、裁撤戍兵、邕州与海门的转运防御连读。《通鉴》记李鄠杀杜守澄后其宗党引兵，又记蔡京主张罢戍、蔡袭请留不获，随后蔡袭死于交趾。不能只将失地归因某一族群“反复”，也不能用援军调令已下推定粮兵已到。865—866年的复取另按战报与任免过程研究。[^南]

868年新设定边军的主张涉及巂州、邛州、成都之间的远近与节制；869年末至870年，南诏进兵、成都集中人口、修守备与募突将相互牵连。相关军费和征发也连接内地社会，但不能将庞勋发生说成南诏单方面直接制造。军役延长是经过唐方财政和军府决定作用于军人的过程。[^蜀]

## 其他兵变与民众抗争也要进入视野

862年蔡京在岭南西道施刑苛酷而被军众驱逐；869年陕州民诉旱被崔荛拒斥、杖责后逐使，属于州民与地方行政冲突；同年沧州卒擅归、曹翔诛其违命者，则是官军体系内部的纪律与人身安全问题。总览先列其性质与出处，不据“乱”字将军人和百姓合成同一类主体。[^他]

## 河西并行政治与资料分歧

张义潮收复凉州，两史本纪与《通鉴》有862、863的系年差别，本朝编年保留各书记法，不把同一行动重复计为两次。嗢末在862年前后入贡及其部落形成的叙事，又提示吐蕃旧政治组织瓦解后人口依附关系发生变化；唐廷所用“蕃汉”“奴”等称谓有特定语境，不能直接转换成现代民族身份。[^西]
