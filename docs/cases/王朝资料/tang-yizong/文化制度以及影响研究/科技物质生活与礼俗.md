# 唐懿宗：科技物质生活与礼俗

专题编号：YZ-C11。整理日期：2026-10-23。范围：YZ-860-03、YZ-862-04、YZ-867-02、YZ-873-01；跨朝陆龟蒙材料。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

<a id="case-analysis"></a>

## 材料与叙述

本期地方工程有都昌陈令塘、祁门阊门滩及建昌筑堤；867年高骈奏开凿水路险石，材料证明工程与漕运组织，未给出可重建的凿石工艺。[^一] 873年迎佛骨的彩棚、香舆、音乐、仪卫与观礼，是礼仪消费场景，不能概括普通家庭衣食。[^二]

## 人物、制度与空间关联

陆龟蒙传记叙低田受潦、亲持畚锸、顾渚租茶、品水及舟中茶灶，且有田数百亩而常饥；须同时看到田产、灾害、租佃与文人生活理想。该材料宽年代跨两朝，不硬系某年。[^三]

参[编年纪事](../年事/编年纪事.md)、[本纪与人物群体](../纪传体/本纪与人物群体.md)、[历史地理](../古地理与行政区划/历史地理.md)。同一事件沿用原编号，专题编号用于研究归类，不另算一次历史事件。

## 合论与证据边界

饮食柴米油盐酱醋茶与酒曲分别追查。茶药通商不等于煎茶法；榷酒收入不等于酿造工艺；病酒后不饮的个人经历也不等于禁酒令。服饰与民间礼俗仍缺材料。

## 从制度背景解释本朝个案

地方塘堤、阊门滩和安南水路工程，显示本朝技术应用常由州县或军府组织。陆龟蒙田产受潦、租茶与舟中器具的宽年代材料，又将工程、农业风险和文人消费联系起来。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《从工艺流程到日用制度和文化选择》](../../../背景综述/晚唐时期背景综述/科技物质生活与礼俗.md#background-mechanism)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

生活史不应只写皇室奢侈与战争饥饿两个极端。常态生产、文人消费、官府课税和非常求生须分别呈现；衣食、器物与礼仪中的等级差异，也要从对象、场合和资源条件解释。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
