# 唐懿宗：历史地理与行动通道

整理日期：2026-10-23。本表使用史书当时地名，尚未建立现代坐标或历史疆界多边形；下列通道是文本所见联系，不是测绘路线。编年对应见[年表](../年事/编年纪事.md)。

| 空间组 | 时段与编号 | 本轮可确认关系 | 不可据此推出 |
|---|---|---|---|
| 越、剡、宁海与浙东海岸 | 860，YZ-860-01 | 王式军通过陆路、海口封锁等方式围攻裘甫；可同时看山地、县城和海道。 | 起事范围内每县均持续被占领。 |
| 广州—邕州与岭南东西道 | 862，YZ-862-02 | 以广州、邕州为中心设置两道，并割龚、象、藤、岩等州调整管辖。 | 方镇辖区等同今日省界或国界。 |
| 福建—广州海运、湘漓内河 | 862—864，YZ-864-02 | 军粮由内河溯运转而利用海运；商船和货物受到征发影响。 | 海运完全替代全部陆路和内河运粮。 |
| 安南／交趾、海门、邕管 | 863—867，YZ-863-01、YZ-866-02 | 陷城、行交州安置、复城、静海军建置和水路工程分别发生。 | 安南与南诏是同一政权；一个古名可直接套一条现代边界。 |
| 徐—宿—濠—泗及桂州 | 862—870，YZ-862-03、YZ-868-01 | 募兵、远戍、返乡、起事和战后军额复置形成往返联系。 | 军镇整顿只影响某一座城，或战败后全部逃户立即回籍。 |
| 巂州—大渡河—黎雅—成都 | 869—870，YZ-869-03、YZ-870-01 | 南诏进军、唐军防守及运输征发连接高原边缘与成都。 | 南诏所有行动均是同一目标和同一支军队。 |

## 战后人口、土地与地方制度

869年战后徐、宿、濠、泗的税役与田宅归还条款，872年禁止摊派逃户赋役的条款，可作为人口流动与土地承佃研究的起点。这里先记录政策覆盖的州与对象，不把诏令解释成已经完成土地重新分配。[^土地]

## 地理志的使用边界

本轮地理组主要从本纪和编年材料的实际行动、任官与隶属变化提取，尚未完成本朝所有州县逐条地理志对校。后续优先对《旧唐书》地理志三、四及《新唐书》地理志中的河南道、江南道、岭南道、剑南道条目核对置废年次；地理志常追叙不同时期，不能把一卷表述都当作862年同一幅行政图。现代对应、海岸港口、道路精确线位未核。

## 本轮地理志补核：水利、建县与迁治

《新唐书》卷四十一的都昌、福州永泰、南陵、祁门、建昌条，分别提供860年陈令塘、861年置永泰县、862年阊门滩及建昌堤、864年永丰陂材料，已按实际年次补入编年表；其中祁门工程可见穴石、积木和派渠的具体动作，不据此推定全朝统一技术。卷四十二资州条载865年徙内江、866年复盘石，也分别列条。[^地理志补]

旧志安南府条以邕管为参照，并追述交州、安南都护府等更名；同卷岭南五管与黎州诸条提供机构和通道背景。它们包含不同时期的信息，不能拿其中的天宝户口数字代表懿宗朝人口。[^旧志补]

## 从空间进入独立事件

浙东从象山、宁海、剡县到越州的海陆道路，与徐宿—汴水—濠泗—淮口的漕运链是两组空间。进士提出的取扬州、福建之议不等于已经到达的行军路线；庞勋战事又须分北返道路、占领区、围城与官军反击线。
