# 唐宣宗时期历史地理初表

整理日期：2026-10-19。以两《唐书》地理志为地理骨架，以本纪及《资治通鉴》定位变化年月。出处代号见 [史料与待考](../史料与考证/史料与待考.md)，N、Z编号见 [年事初表](../年事/编年纪事.md)。

**时间处理原则**：地理志是历代沿革汇记，州下列县、户口、军镇未必属于同一年代。表内只把明确系“大中某年”的变化归入宣宗朝；未系年的县属、人口、土贡与道路列作背景，不自动视为850年前后的现状。粗定位只作查图提示，未经现代历史地图逐点校核，不据此绘制边界。

## 二、河西十一州与归义军

851年的“十一州”名单，两《唐书》本纪、《通鉴》与X40陇右道总叙可互参：**瓜、沙、伊、肃、鄯、甘、河、西、兰、岷、廓**。X40总叙同时评价“惟名存有司而巳”，说明同一部史书内部已对行政经营程度有所保留；不应只取“尽入于唐”的一句作实控边界。

| 对象 | 本次可确认的史料层次 | 可用的地理志材料 | 整理限制 |
|---|---|---|---|
| 沙州、归义军 | 851接到归附报告，十一月置归义军，张义潮任节度使。 | J40沙州记敦煌、寿昌及阳关、玉门关等；X40沙州也列敦煌、寿昌。 | 志中所列“户四千二百六十五、口一万六千二百五十”不能当成851人口普查。沙州为今敦煌地域的查图入口。 |
| 瓜州 | 851十一州之一。 | X40瓜州记晋昌、常乐及合河镇、百帐守捉、豹文山守捉、宁寇军路线。 | 地理志道路、守捉不等于851全部仍在运作；本处常乐县也不得与改威州的长乐州混同。 |
| 甘州、肃州 | 851十一州之二；存在河西军事交通联系。 | 两书地理志可提供旧县、军镇、土贡背景；X40甘州有建康军、蓼泉守捉等。 | 具体收复先后与控制程度尚待敦煌文书；今张掖、酒泉地域仅作查图提示。 |
| 伊州、西州 | 851进献名单中有二州。 | J40分别有伊、西州条，X40也收陇右诸州与西域道路。 | 列入图籍不等于直接证明唐在哈密、吐鲁番整个地域稳定驻军；现代地名仅粗定位。 |
| 鄯、河、兰、岷、廓 | 名单覆盖河湟与陇右多个区域，不能全称为河西走廊同一地带。 | X40与J40沿革、山川、军镇条可以互校。 | 需要区分地方首领归附、朝廷名号、图籍进献与实际州县运行。 |
| 凉州 | 不在本次核到的851十一州名单内。 | 两书地理志有凉州旧制，可作交通和区域背景。 | G2所说861收复属懿宗朝；须另查原始文书，不列为宣宗期既成收复。 |

## 四、地理志后续覆盖范围

本轮实际抽核：J38原州萧关；J40秦、成、沙等州；J41维州；X37原、武、威、陇等州；X40秦州及山南西道部分县；X42维州。尚未完成两书地理志所有卷的逐条扫描。

下一轮应按《旧唐书》卷38—41、《新唐书》卷37—43下通检“大中、会昌六年、复置、徙治、来属、置军、关、驿、堰、渠”等词，另外记录没有准确年份的相关条文。方镇表和列传用于核军镇辖属、驻地、人员及边疆事件；食货志和《唐会要》用于漕运、营田、赋役补证。

建库建议字段：地名原字、异名、对象类型、所属层级、变化前、变化后、最早／最晚日期、史料卷篇、原文、地理志材料时间、今地比定、比定依据、争议说明。单独保存“史籍载某变化”与“研究者认为的空间范围”，方便以后修订。
