# 宣宗朝：李德裕退出与政治结援

2026-10-19，第一版。与[纪传体专题稿](../纪传体/本纪与人物群体.md)、[编年年事表](../年事/编年纪事.md)及[地理初表](../古地理与行政区划/历史地理.md)互参。这里把两条主线放在一起，是为了调查中枢人事如何作用于地方任命、地方资源又如何影响中枢；不是预设二者能解释一切。

## 一、牛李党争：宣宗朝的重点是人事重排、余波与政治记忆

### 第一层：把会昌背景与大中当年分开

李德裕在武宗时的用人、泽潞用兵、与监军关系，说明846交接时各方继承了怎样的资源和矛盾；不能全部重复统计为宣宗朝发生的事件。牛僧孺、李宗闵及李德裕的政治经历也有不同，不宜以两人姓名涵盖所有同时在世人物。

宣宗朝先核四个观察点：846后李德裕罢相及旧贬官迁转；847—848吴湘案再审及扩大处分；849李德裕贬所去世；此后令狐绹等长期任职、士人出路和后朝追诉。传统所谓“党争终结”，若使用，必须说明是领袖退出、朝廷阵容改变，还是政治网络和排斥机制消失；三者不是一回事。

### 第三层：三组必须对读的争议

**吴湘案：司法纠错与政治用途。** J18大中元年九月、二年二月有吴汝纳申诉和处分材料；J174把再审置于排斥李德裕的叙事中；X180附录又着重记录受牵连者。应做“原审—复核—定罪—政治扩大”的程序表，对每项证据注明由谁提出。不能先认定全部为冤案平反，也不能先认定全部捏造。对应B01。

**维州：旧日争论与849新形势。** 李德裕传追论太和五年维州受降、返还一事，属于前朝政治争论与边疆政策背景；849维州内附则是新事件，见N13。两次应分记录。讨论牛李在边疆策略上的差别，要把盟约、兵力、地形、补给和政治竞争并看，不能据一次争论写成两个派别一贯不变的“主战／主和”纲领。

**实录与史书：谁塑造前朝功过。** J18、T248记《宪宗实录》版本取舍，X182周墀传也涉及改修争议。J174高度肯定李德裕会昌功业，同时对大中用事者严厉；J18保留指责李德裕的制文，J172又褒牛僧孺。制书、传记叙述、赞论与当事人自述必须分栏，不将政治修辞直接当成已核事实。

## 二、方镇势力：按地域与运作方式比较

以这些指标分别描述，比给每镇打一个“割据／不割据”的标签更能解释事件。某镇能自定主帅，不一定同时独占所有税源；某镇按朝命易帅，也可能被牙军频繁驱逐。

## 三、两条主线如何相接

李德裕罢相出镇、郑亚处分及李商隐迁幕，是中央关系影响地方职业与行政人事的具体联系；裴休整顿漕运、李珏争税酒，则显示地方财政和禁军利益如何进入中央议政。它们可以作为已证实存在联系的案例。

还应检验但目前不能下定论的命题包括：大中朝各镇长官是否按党争关系成批调换；某次逐帅是否利用中央政敌声援；税源争夺能否解释特定军乱；宦官监军是否在某镇联合地方集团。每个命题都要补具体任命、通信、钱粮和执行材料，不能仅以“晚唐党争严重、藩镇强大”推出结论。

研究记录统一采用：**谁在何时、何地，以什么职务和资源，支持或反对谁，采取什么行动，造成什么已可核实的后果**。人物传、编年表和地理表共用编号，便于反查并修正。
