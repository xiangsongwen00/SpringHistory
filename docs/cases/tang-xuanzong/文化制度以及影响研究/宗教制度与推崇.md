# 唐宣宗：宗教制度与推崇

专题编号：DX-C08。整理日期：2026-10-23。范围：846—859；会昌政策为背景。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

<a id="case-analysis"></a>

## 材料与叙述

846年长安两街寺院获准保留恢复、847年会昌废寺在名僧等条件下可修创，说明政策转向但仍有条件。[^一] 《食货四》还把会昌铜器铸钱与宣宗新钱复铸为像相接，可研究宗教复兴与物质资源之间的联系。[^二]

## 人物、制度与空间关联

长安两街、州府及名山寺院应分开建目录；皇帝、地方官、僧团、檀越及原寺产占有人不应只用“崇佛”一词代替。

参[编年纪事](../年事/编年纪事.md)、[本纪与人物群体](../纪传体/本纪与人物群体.md)、[历史地理](../古地理与行政区划/历史地理.md)。同一事件沿用原编号，专题编号用于研究归类，不另算一次历史事件。

## 合论与证据边界

恢复寺院数、僧尼度牒、寺产归还、道教待遇与地方祭祀尚待专项核实。准予恢复不能直接证明原寺产全数返还。

## 从制度背景解释本朝个案

宣宗朝应重点解释有条件恢复怎样落在长安两街、州府和名山不同场所。将寺院存废与铜料、寺产、人户身份相联，才能呈现宗教政策怎样改变社会资源配置。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《寺院、国家仪式与社会资源的重新分配》](../../晚唐时期背景制度综述/宗教制度与推崇.md#background-mechanism)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

三朝的宗教研究应把政策、资产、仪式和生活分开，再说明它们如何结合。会昌到大中的转折可以明确叙述，但恢复程度、地方差异与群众动机仍须按证据限定，不能用“崇佛”包办。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
