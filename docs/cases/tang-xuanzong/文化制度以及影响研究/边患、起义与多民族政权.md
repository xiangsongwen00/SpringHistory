# 边患、起义与多民族政权的发展：晚唐至元研究框架

<a id="case-analysis"></a>

编写日期：2026-10-19。当前成果是研究框架及唐宣宗时期案例初录；不是已经完成的晚唐至元通史。与[纪传体专题稿](../纪传体/本纪与人物群体.md)、[本朝政治人物与结援](../专题研究/政治人物与结援.md)、[编年表](../年事/编年纪事.md)、[地理表](../古地理与行政区划/历史地理.md)互相对应。

## 一、将多民族并行、互动与融合发展纳入主框架

按用户提出的视角，将晚唐至元作为比较各族群、政权与区域社会发展的长时段。中华各民族及其建立或参与的政权，既有自身的制度、经济与文化发展，也在战争、贸易、迁徙、婚姻、宗教和行政实践中互相作用。对具体历史过程，应分别记录并行、竞争、交往、融合及其反复，不预设每次接触必然推动融合，也不以最终政治整合倒推当事人的选择。

专题采用“边患与起义”和“族群、政权及周边关系”两个相连部分。这样既保留唐宋等朝廷感受到的边境压力，也能给其他政权和地方社会自身的经历留下篇幅。研究中华少数民族政权，同时将其与周边政治体的关系列入；不把所有往来的政治体都归入同一种历史身份。

“少数民族”用于说明现代研究方向；条目记录具体时期的族称、自称、政治身份和所属政权，不把古代族称直接等同今天民族识别，也不把族群、部落、军队和国家当作同一层级。一个政权内部的多种群体与不同政治选择，也要保留。

## 二、边患与起义：先辨行为和参与者

| 类别 | 需要辨明的事实 | 与现有材料的连接 |
|---|---|---|
| 政权间战争与边境冲突 | 发起者、目标、兵力、补给、地形、战后安排；双方记载如何命名 | 唐与吐蕃诸部、南诏及其他边地力量的关系 |
| 政权内部争夺 | 争位、地方首领竞争、部落或军队分裂、对外求援 | 吐蕃论恐热、尚婢婢等势力的冲突，不能写成一个统一吐蕃行为 |
| 地方武装反抗、民众起事 | 首领、参加群体、诉求、组织、资源、行动与镇压 | 沙州起事；后续另查裘甫及跨朝起事，不能预定其参加者皆为农民 |
| 军乱、逐帅、拒绝移戍 | 将校、牙军、戍卒、家属、粮饷、轮替、指挥关系 | 武宁、卢龙及858年南方诸镇；不与民众起义合并 |
| 官府所称“盗贼” | 是否抢掠、走私、结社、抗税或争夺地方权力；记载者是谁 | 茶盐经营与地方治安材料；不能从一个“盗”字确定阶层和动机 |
| 归附、脱离与改属 | 谁代表谁、接受何种职号、有无驻军、纳税和实际控制 | 三州七关、沙州归义军、边疆首领与唐廷联系 |

每次事件同时记录政治影响和社会影响：死亡与俘获、人口迁移、村落与耕地、军粮和税负、贸易路线、劳役、宗教场所及战后安置。没有材料的项目留空，不能将一般战争经验当成个案事实。

## 三、宣宗时期案例：用已有史料把视角落地

| 案例 | 已核材料与事件编号 | 新增观察方向 | 目前不能下的结论 |
|---|---|---|---|
| 吐蕃内部冲突与河陇变化 | T248三年、T249四—五年叙论恐热、尚婢婢、拓跋怀光等；N08—N16 | 各势力的地方基础、部落迁移、城堡粮源，与唐军接收之间的联系 | 唐收复全部由单一军事胜利造成；或吐蕃内乱只有一个原因 |
| 南山、平夏党项 | T249五年记边帅侵夺羊马、妄杀，后授闲田、赦降与给复；N20、N22、N31 | 市场交换、边官行为、饥寒、土地安置、部落选择和军事回应并看 | 将所有冲突解释成自始不变的民族敌对；或把平夏、南山视为同一组织 |
| 沙州起事与归义军 | T249五年二月追叙起事，十一月置军；N06、N24—N25 | 地方动员、政治认同、朝廷授职、当地族群与宗教网络 | 正史所称“唐人”可直接换算今天民族身份；十一州图籍等同全境稳定控制 |
| 回鹘与黠戛斯等关系 | T248关于回鹘部众离散及其与其他力量关系；T249十年册命，N41 | 部众迁徙、政治重组、使节路线、贸易与军事服务 | 将不同地点、不同首领与阶段的回鹘活动写成一个始终统一的国家行动 |
| 南诏—安南—地方部落 | T249十二年记峰州林西原、李由独部及边官政策前因；N44、N47 | 边境基层军事、牛马交易、首领婚姻与政治依附，分别从各方观察 | 以朝廷单方的“寇”概括全部关系；将追叙前因都系于858六月 |
| 维州及川西地方首领 | 两书地理志、T248三年；N13，G08 | 地方首领受官、正州与羁縻旧制、守捉和交通，核地方社会能动性 | 羁縻必然等于直接治理，或内附便使地方习俗与权力结构完全改变 |
| 内地军乱与民众 | N40、N43、N45—N50、N53 | 比较军饷、将校、地方税源和普通居民受害、应对 | 将逐帅全部归入农民起义，或因时间相近认定是统一行动 |

其中，851年党项案例尤其适合多角度分析：史书本身即记边将侵夺、饥寒与边地安置；因此可以同时研究唐廷政策、地方军政、部落经济与行动选择。依据为[《资治通鉴》卷249](https://zh.wikisource.org/wiki/資治通鑑/卷249)大中五年二—四月、八月等条。史书的因果解释仍须与其他材料对读，不能直接当成已穷尽的原因。

十一州材料则应保留两种叙述：《通鉴》有归复总叙，[《新唐书》卷40陇右道总叙](https://zh.wikisource.org/wiki/新唐書/卷040)又保留对实际经营程度的评语。两者正适合区分政治名义、地方控制、行政运行和区域交往，不据一句话画出单色疆域。

## 四、族群和政权发展：每个对象都考察自身历史

| 维度 | 具体调查内容 |
|---|---|
| 政治形成与内部关系 | 首领及统治集团、继承方式、地方权力、不同群体参与，避免只写与中原朝廷往来 |
| 制度与资源 | 官号、法令、财政、征役、军队、土地与水利；分别核本地创制、借鉴和调整 |
| 经济与交通 | 农牧、手工业、矿盐、贸易、互市、关津、商人及运输；同时记录合作与限制 |
| 人口与聚落 | 主动迁徙、逃难、俘掠与强制迁徙、军户、通婚、城镇及乡村布局 |
| 语言、文字与知识 | 称谓、翻译、文书、教育、文本传播；区分统治者用语与普通社会实践 |
| 宗教与文化 | 寺院、僧侣、仪式、艺术和技艺流动；交往是否依赖商路、使节或政治资助 |
| 认同与交往 | 政权归属、地方认同、家族和宗教联系如何交叠；不能假定单一身份涵盖个人全部关系 |
| 战争与融合的后果 | 谁获利、谁失地、谁被迫迁徙、怎样恢复生产；交往融合与痛苦经历可以同时存在 |

## 五、晚唐至元的长时段比较安排

下表为待展开的选题范围，不表示这些政权在每个阶段都同时存在，也不表示它们同属一种建国过程。当前并未完成下列各朝史料核读。

| 比较阶段 | 拟纳入的对象与联系 | 主要问题 |
|---|---|---|
| 晚唐 | 唐廷、方镇、归义军、吐蕃及其后续地方力量、回鹘诸部、党项、沙陀、契丹、南诏、渤海等 | 帝国秩序变化中，地方政权与族群关系如何重组；贸易、军事服务和迁徙怎样相接 |
| 五代及区域政权并立时期 | 中原各政权与南方诸国、契丹／辽、河西诸势力、党项集团、吐蕃诸部、大理等 | 军政集团、家族与地域形成政权的路径；制度和人口如何跨界流动 |
| 宋、辽、西夏、金等并立与交替阶段 | 各政权及其内部不同族群、边地社会、大理与高原诸势力等 | 战争与盟约、边界与市场、财政军役和多种治理制度的关系 |
| 蒙古兴起、扩张至元 | 蒙古各政治力量、元及被纳入其统治的不同区域和群体 | 军事整合、行政重组、人口与工匠迁徙、交通网络、宗教与文化交往及其不平等条件 |

保持两种尺度：各政权自身的阶段性发展，与跨政权区域网络的长期变化。后者可按河西、燕云、河套、四川—云南、高原及其他交通区域组织，不能只按朝代更替截断联系。

## 六、材料与记录方式

唐宣宗阶段继续以两《唐书》《通鉴》为入口，补地理志、方镇表、相关族群和政权列传、《唐会要》及敦煌文书。进入后续时期后，需扩充各朝正史、实录或编年材料、碑刻、契约、考古、图像和非汉文材料；尚未核读者均列为待查，不能沿用唐代制度解释元代。

新增字段：史料称谓、现代整理名称、自称／他称、对象层级、所在地域、政治归属、内部派别、行为类型、诉求、资源、对手与合作者、居民影响、交往形式、强制程度、实际控制依据、双方／多方材料、研究争议。

编年表记录“发生了什么”；纪传体记录“人物、制度和群体怎样行动”；本专题进一步记录“并行的政治力量与社会怎样互相改变”。同一事件可同时标注党争、方镇、边疆、起事、商贸、迁徙等多个角度，但保持一条可追溯的史料依据。


## 从制度背景解释本朝个案

河陇接收、归义军授节与吐蕃实际控制变化应分节点。册命、图籍和名义辖境不是稳定实控的充分证据；边地授田、道路与盐利才是进一步解释长期经营的材料。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《从唐廷边疆到并行政治世界》](../../晚唐时期背景制度综述/边患、起义与多民族政权.md#background-mechanism)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

晚唐至元可以作为多政权并行与交往融合的长时段研究，但本册只完成三朝主要问题的框架与个案。比较时应沿军政组织、贸易人口、语言文化和统治合法性分别追踪，不预设从分裂必然走向某个统一终点。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
