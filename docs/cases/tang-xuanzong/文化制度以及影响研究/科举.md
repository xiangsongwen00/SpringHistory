# 唐宣宗：科举

专题编号：DX-C07。整理日期：2026-10-23。范围：847、856及大中时期文人经历。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

<a id="case-analysis"></a>

## 材料与叙述

大中元年魏扶以父兄居重位为由将封彦卿等三人另奏，宣宗命韦琮重考，认定文字合程而准及第，并要求有司至公、不必再别奏。此例显示门第关系与考试文本都被用于论证资格，不能据此宣称门第特权消失。[^一] 856年停部分科目三年、严童子荐送，与进士考试应分科记录。[^二]

## 人物、制度与空间关联

礼部、翰林复考、父兄任职、杏园宴集和幕府聘辟形成不同进入官场的环节。李商隐等人的交游另参文学与人物群体。

参[编年纪事](../年事/编年纪事.md)、[本纪与人物群体](../纪传体/本纪与人物群体.md)、[历史地理](../古地理与行政区划/历史地理.md)。同一事件沿用原编号，专题编号用于研究归类，不另算一次历史事件。

## 合论与证据边界

科目、荐送、及第、授官不是同一过程。尚缺完整登科名单、试卷、地区与家族分布；不从个案推全国社会流动率。

## 从制度背景解释本朝个案

宣宗复考不等于否定一切门第影响，而是把亲属显位与文字能力的冲突交给皇帝、翰林重新审定。研究这件事要同时写礼部裁量、复考权与宴集关系，而非只评皇帝重视人才。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《教育、贡举、铨选与关系网络》](../../晚唐时期背景制度综述/科举.md#background-mechanism)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

科举既提供可共同评价的文字标准，也生产师生、同年和礼仪关系。它不能被写成完全排除门第的公平机器，也不能被缩成权贵私相授受。研究应追踪不同环节如何打开或限制具体人的机会。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
