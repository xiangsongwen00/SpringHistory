# 科技、物质生活与礼俗：服饰、饮食、酒曲与酒茶专题

整理日期：2026-10-19。新增专题框架与首批史料线索。当前以唐宣宗朝为核心，兼作晚唐至元长时段比较的分类方法；没有完成各时期生活史通检。与[纪传体总稿](../纪传体/本纪与人物群体.md)、[多民族政权研究框架](边患、起义与多民族政权.md)、[编年表](../年事/编年纪事.md)、[地理表](../古地理与行政区划/历史地理.md)互参。

## 一、研究范围与共同问题

将科技、服饰、礼仪民俗、饮食和日常消费作为正式研究视角。这里的“科技”既包括知识与器具，也包括生产、加工、保存、运输及工程技术；不只编发明年表。“柴米油盐酱醋茶”作为今天整理日常生活的检索目录，不预先认定唐人使用同样的成套说法，也不认定各地家庭都有相同消费结构。

每项沿四条线整理：**怎样生产和使用—怎样流通—谁制定或执行规则—不同人群怎样生活**。同时记录其与土地、财政、军需、商人、寺院、家族、身份和族群交往的联系。

## 二、科技与生产生活技术

| 领域 | 调查内容 | 主要证据与判断要求 |
|---|---|---|
| 农业与水利 | 农具、耕畜、种植、灌溉、堰渠、营田、仓储 | 技术名称、材料、结构、操作、使用地域、修造时间与效果分别核；修旧不等于新发明 |
| 食品与发酵 | 粮食加工、炊具、制曲酿酒、酱醋、茶叶加工、腌藏 | 配方、工序、器皿、原料与计量；现代实验复原另标，不假称古人已有同样理论 |
| 纺织与服饰 | 纤维、织造、染色、缝制、皮革及饰物制作 | 制度规定与实物并读，不从衣料名称独自还原完整工艺 |
| 燃料与冶炼 | 采薪、木炭及其他燃料、矿冶、制盐、烧造 | 资源地、劳力、燃耗、交通和管理；有产量记载不直接证明技术创新 |
| 交通与建筑 | 船、车、驿路、关堡、桥梁、城防、排水 | 工程制度、工匠、材料来源及维护成本，联系地方财政和军需 |
| 医药、历算与知识传播 | 医疗实践、药材、历法天文、书写复制及相关器具 | 医书或方书说明知识记载，是否实际采用需另证；注明成书与所述事件年代 |

对“发展”分阶段记录：最早可证记载、实物年代、局部使用、传播、普及、制度采用。不能把一件器物或一条书面记载直接写成全国已经普及，也不把原有技术在新区域使用误作发明。

## 三、服饰、礼仪与民俗

| 对象 | 考察项目 | 要区分的层次 |
|---|---|---|
| 服装与装饰 | 冠帽、袍衫、裙裳、鞋履、腰带、佩饰、发式、材质与颜色 | 礼服、公服、军服、便服；赐服与实际穿用；身份、性别、职业、年龄和地域差异 |
| 婚礼与家礼 | 聘娶、婚资、车服、宴席、入门与亲属义务 | 宫廷、公主、官僚、地方家庭；规范、争议与实际个案 |
| 丧葬与祭祀 | 丧服、送葬、墓葬、宗庙、地方祭祀与祖先纪念 | 礼典条文、朝廷临时决定、墓志叙述与考古现象 |
| 岁时与节庆 | 节日、宴饮、出游、祈禳、演艺与馈赠 | 官方仪式、地方风俗、寺观活动和家庭实践 |
| 礼仪与身份 | 朝会、宾礼、使节接待、军中仪式、赐物与服色 | 谁主持、谁参加、谁承担成本；政治表达不直接等于群体生活全面变化 |
| 跨区域交流 | 衣饰、饮食、音乐与仪式的流动和改造 | 传播路线、参与者、使用场合与当地再解释；不据相似外观断定唯一来源 |

礼典规定回答“应当怎样”，地方记录和实物帮助回答“实际怎样”。诗歌、笔记中的豪华服饰或宴饮还涉及修辞、文学成规和社会评价，不能单独作为普通人生活水平的统计。

## 四、柴米油盐酱醋茶：逐项建档

| 项目 | 生产与流通 | 生活、制度与社会问题 | 目前资料状态 |
|---|---|---|---|
| 柴 | 采薪、炭窑、运输、市场与消耗 | 灶火、取暖、烧造、制盐酿酒的燃料竞争；价格与资源负担 | 专题待检，尚无宣宗朝完整价格或消耗表 |
| 米与其他主粮 | 种植、收获、碾磨、储藏、漕运、军粮 | 粮食供给、地区主食差别、粮价、灾荒、赈济、酿酒用粮 | N21保护耕牛、N23漕法、N29仓储、N39灾荒可互参；不能用“米”代全部粮食 |
| 油 | 原料、压榨或其他取油工艺、买卖 | 食用、照明、医药等用途分别核，不预定全部为烹饪用途 | 原料和工艺待专题核证 |
| 盐 | 盐池、盐井、海盐、加工和运输 | 官盐私盐、亭户、税价、军需与家庭购买能力 | B02及既有食货专题有初录；各盐区技术不能混同 |
| 酱 | 原料、发酵、储藏、家庭与作坊 | 配餐、地方差异、生产者与市场；古今同名物须辨 | 配方、年代、地域待核 |
| 醋 | 原料、酿造、保存、流通 | 饮食调味及其他用途逐条核；与酒生产的联系不能只凭现代经验推断 | 宣宗朝直接材料尚待检索 |
| 茶 | 产区、园户、加工、包装、储存和运输 | 饮法、器具、待客、寺院、商路、税茶、私茶与地方横征 | B03、B05及X54有政策材料；具体茶法与饮法须另找同时代证据 |

消费比较需按地域、季节、身份及城乡分别记录。没有数量或价格证据时，不补写人均消费和家庭预算；不同年代斤、两、斗、斛和货币也不直接换算成现代统一数值。

## 五、酒曲、酒政与酒文化

### 制曲与酿酒技术

把曲的原料、制备、储存、使用工序及操作知识单列。曲、糵等史料用字各自保存，辨其具体含义；不将古代发酵知识直接写成现代微生物学。酒的原料、加工、过滤、保存、运输和器具也分别核证。蒸馏相关技术及其年代是另需证据的题目，不因“烧酒”等名称便认定与现代同名酒相同。

### 政策与利益

“酒禁、榷酒、榷曲、酒税、官酿、私酿”分项记录，不能混为一项全国统一制度。政策表应有发布地点、适用人群、税率或课额、执行机关、实行期限、豁免、案件及争议。

优先调查禁酒与粮食、灾荒及军需是否相关，榷曲和销售管理怎样影响家庭、作坊与酒商，酒利在中央、方镇、军队和地方豪商之间怎样分配。政策发生变更，不直接证明民间完全照办。

### 文化与习俗

分别考察祭酒、婚丧宴饮、节庆、军中犒赏、使节接待、文人唱和、酒肆与家庭饮用。酒器、座次、劝酒、酒令、音乐表演、赠答和禁忌可作研究项目，但具体存在与样式均须给出时代、地域与出处。诗中酒意象、作者自述和实际饮用三者不互相等同。

## 七、补证材料和记录字段

继续以两《唐书》食货、礼仪、车服等志及相关列传、《通鉴》核政策与事件；《唐会要》用于制度补证。再查相应时期的农书、食经、茶书、医药书、文集笔记、账簿契约、出土文书、壁画、墓葬和传世器物。尚未直接阅核的书和实物只列待查，不写作既得证据。考古报告和器物图录须核地点、年代、出土组合，不能仅凭网络图片定时代或族属。

统一字段：对象原名、异名、类别、日期范围、地域、使用者、身份与性别、原料、工序、器具、用途、计量、价格、交易与运输、税禁、礼仪规定、实际实践、社会影响、交流路线、出处、记载层次、争议和置信程度。

进入晚唐至元比较时，每一时期重新核当地制度和词义。技术传播与文化交流记录多种方向、本地改造和不同群体的选择，不先假定单向传播，也不把技术改进、财政增收和生活改善视为必然同时发生。


## 从制度背景解释本朝个案

万寿公主婚礼、赐绯及河陇“袭冠带”是不同等级和政治场合的服饰材料。它们可以说明器物、身份与礼仪如何结合，却不能直接复原全部民间衣着；与茶法等可描述工艺的材料应区别处理。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《从工艺流程到日用制度和文化选择》](../../晚唐时期背景制度综述/科技物质生活与礼俗.md)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

生活史不应只写皇室奢侈与战争饥饿两个极端。常态生产、文人消费、官府课税和非常求生须分别呈现；衣食、器物与礼仪中的等级差异，也要从对象、场合和资源条件解释。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
