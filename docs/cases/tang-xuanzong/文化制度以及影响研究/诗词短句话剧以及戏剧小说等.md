# 唐宣宗：诗词短句话剧以及戏剧小说等

专题编号：DX-C09。整理日期：2026-10-23。范围：846—859主体；文人生平前后另标。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

## 材料与叙述

李商隐与令狐楚、令狐綯、王茂元之间有旧主资助、婚姻、幕府和仕途关系，须将各类关系分别记录；两史传记的政治评价不能直接充作每首诗的创作年月与寓意。[^一] 宣宗本纪叙曲宴属和、出镇赋诗饯行及杏园宴集，可从宫廷和士人交往场景观察文学活动。[^二]

## 人物、制度与空间关联

诗文作者、作品、场合、传播与后世解释分别建项；与科举、幕府任职、家族网络联读。短句作为引文形式，不另造古代文体。

参[编年纪事](../年事/编年纪事.md)、[本纪与人物群体](../纪传体/本纪与人物群体.md)、[历史地理](../古地理与行政区划/历史地理.md)。同一事件沿用原编号，专题编号用于研究归类，不另算一次历史事件。

## 合论与证据边界

本目录沿用用户名称；“话剧”仅作检索提示，不称本朝已有现代话剧制度。戏剧、小说需另核本期文本和演出材料，不能用后世通行故事补唐人生活。

## 从制度背景解释本朝个案

李商隐、杜牧等人的作品必须先处理版本与系年，再进入党争解释。宣宗朝曲宴属和、出镇饯诗也提示文学进入官僚礼仪；官职、文学声望与政治立场不能用一个标签互换。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《文学作为作品、交往和政治行动》](../../晚唐时期背景制度综述/诗词短句话剧以及戏剧小说等.md#background-mechanism)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

文学材料的价值不只在为政治史增添名句，而在说明人如何求职、表达、交往、取得资源并与权力相处。作品审美分析与社会制度分析可以互相支持，但不能互相替代。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
