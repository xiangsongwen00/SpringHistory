# 唐宣宗：税收及徭役

专题编号：DX-C03。整理日期：2026-10-23。范围：N12、N29、N38—N39；849—855。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

<a id="case-analysis"></a>

## 材料与叙述

收复三州七关的垦田免税、营田供给与855年差科簿制度，是不同地域和对象的办法。差科簿按户贫富、役轻重，由刺史检署、县令据簿轮差；淮南旱饥又见蠲逋租、减馈运及罢部分常贡抵下户租。[^一]

## 人物、制度与空间关联

皇帝诏令—刺史检署—县令轮差—人户承役，与灾情奏报、义仓赈给相互衔接。收复地不能直接等同内地州县。

参[编年纪事](../年事/编年纪事.md)、[本纪与人物群体](../纪传体/本纪与人物群体.md)、[历史地理](../古地理与行政区划/历史地理.md)。同一事件沿用原编号，专题编号用于研究归类，不另算一次历史事件。

## 合论与证据边界

任期、簿籍和救荒条文可以研究行政流程；执行率、实际户等、徭役天数与民户负担缺少连续记录。

## 从制度背景解释本朝个案

大中差科簿将户等、役轻重、刺史检署与县令轮差结合，意在让差役分配留下可检查的依据。灾免、常贡抵下户租与河陇免税属于不同对象的调节工具，应研究其覆盖面，不能合成一句普遍轻徭薄赋。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《两税、折纳、征期与逃户转摊》](../../晚唐时期背景制度综述/税收及徭役.md#background-mechanism)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

三朝财税研究的核心不是简单判断税轻税重，而是说明定额、估价、交付、运输与执行如何将压力分配给不同人群。诏令可以证明政府希望纠正的弊端，地方账簿才能进一步衡量改变了多少。

本朝的行动、任免及政策事实仍以本篇脚注为据；这段机制解释须与前文个案合读。对未经数据支持的全国比例和执行成效，不作定量断言。跨朝材料不另算一次本朝年事。
