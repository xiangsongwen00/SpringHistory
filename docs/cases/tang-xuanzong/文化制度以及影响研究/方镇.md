# 唐宣宗：方镇

专题编号：DX-C02。整理日期：2026-10-23。范围：N37、N40、N43—N50；大中时期。月份沿史书旧历，不作公历日换算；传记未系年处保留宽年代。

## 材料与叙述

855年邠宁军还邠州，《通鉴》解释为边地形势与粮储变化；同年浙东军逐李讷，858年岭南、湖南、江西、宣州又有逐帅或囚帅。朝廷调邻镇兵讨平，方镇既是地方冲突单位，也是中央动员资源。[^一]

## 人物、制度与空间关联

邠宁的边防驻地、浙东与江西等财赋区须分别定位；连读宦官监军专题的王宗景并坐。

## 合论与证据边界

逐帅并不都来自河北，也不能把军众、节帅、监军当作同一利益主体。各镇控制税、兵、任免的程度仍须逐年列表。

## 从制度背景解释本朝个案

宣宗时浙东、江西、湖南等地军乱说明逐帅并非河北特有。朝廷能调用邻镇兵讨平，也显示诸镇不是一律对抗中央。地方军政是否服从，要按对象和事件区分，不能只画一张“割据版图”。

本篇的解释建立在上述具体材料之上；完整的制度来路、运作环节及另两朝比较见[《从边防指挥到军政财政的地域组合》](../../晚唐时期背景制度综述/方镇.md)。该背景篇分别交代旧制、变化节点与本期证据，不以“沿袭前朝”代替说明。

### 本朝研究应回答到哪一步

方镇势力的变化应写成兵、官、钱、地的重新结合。逐帅、军中推立、朝廷授命、实际到任和收入控制须分别标日期；同一军镇在两年之间也可能发生显著变化。
